# Method-A1 S1–S4 场景设计与可靠性验证计划

## 一、目的与范围

本计划在 Method-A1 反事实签名预测与残差检验框架基础上，设计 S1–S4 四类可靠性验证场景。四类场景用于检验模型在拓扑信息错误、观测信息不完整、网络结构变化和故障信号减弱条件下的诊断稳定性。

本计划只规定场景实验、数据生成与评价原则，不改变 Method-A1 的基本反事实诊断逻辑，不将 S1–S4 拆分为彼此独立的模型。

## 二、设置 S1–S4 的原因

S0 采用正确拓扑和全量观测，主要用于提供理想条件下的上界参考。S0 结果不能代表模型在实际运行条件下的可靠性，因为实际系统可能同时存在拓扑台账错误、量测缺失、网络结构变化和弱故障信号。

四类场景分别对应四种风险：

- S1 检验错误拓扑是否导致候选签名预测和残差排序失效，并进一步观察模型能否区分故障假设错误与拓扑上下文错误；
- S2 检验观测覆盖率下降时，模型能否区分“没有观测到异常”和“系统确实无故障”；
- S3 检验模型是否学习了可迁移的物理规律，而不是记忆固定拓扑、节点编号或馈线规模；
- S4 检验故障阻抗升高、物理响应减弱时，模型能否保持故障检测和候选排序能力。

S4 是附加困难条件，应嵌入其他场景形成组合实验，而不只建立一个孤立的高阻故障数据集。

## 三、统一数据生成原则

### 3.1 配对物理样本与多视图派生

每个基础样本先生成真实拓扑与完整物理响应，再从同一次物理仿真派生不同场景视图。视图可以包括正确拓扑、错误拓扑、关键节点观测、随机稀疏观测和不同故障阻抗。

同一物理样本的不同视图应共享故障位置、故障类型、运行工况和真实物理签名。该设计用于测量信息扰动本身造成的性能变化，并减少重复仿真。

### 3.2 故障类型与运行工况

数据覆盖以下短路类型：

- 单相接地；
- 两相短路；
- 两相接地；
- 三相短路；
- 三相接地。

负荷和分布式电源运行工况应随机变化，避免模型依赖单一运行点。

### 3.3 无故障样本

无故障正常运行样本比例设置为 10%–20%。正常样本也应派生错误拓扑和部分观测视图，以检验信息退化是否造成无故障误报。

定位候选集合中保留“无故障”类别，并在所有场景中报告无故障检测指标。

### 3.4 输入与缺失表示

节点输入使用时间窗口内的电压时序，时间窗口长度 (T) 设置为 20–100 个采样点。缺失节点或缺失观测使用可学习的 MISSING 表示，并同时提供观测掩码，使缺失值与真实零值可区分。

边数据保留线路物理属性及其可用性信息。所有场景样本应保存真实拓扑、观测拓扑、观测掩码和场景参数等元数据。

## 四、S1：错误拓扑场景

### 4.1 实验目的

S1 模拟开关状态、线路连接关系或拓扑台账不可靠的情况。其主要目标不是单纯测量模型在错误输入下的准确率下降，而是检验模型能否判断残差异常的来源：

- 当前故障候选或签名预测错误；
- 当前观测拓扑本身错误。

### 4.2 错误类型与错误率

错误拓扑包括两类：

- 随机翻转：开变合或合变开；
- 状态缺失：线路状态未知，相关拓扑信息不可用。

错误率挡位设置为 0%、2%、5%、10% 和 30%。错误率按统一百分比定义，不按各样本实际错误边数量单独定义。正式实验需固定百分比的分母和取整规则。

翻转和缺失必须分别统计，因为翻转提供错误的确定性信息，而缺失表示信息不可用，二者对模型的影响不同。

### 4.3 真实拓扑与观测拓扑

S1 样本同时保存真实拓扑 (G^*) 和观测拓扑 (G_{obs})。物理故障响应和反事实签名目标由真实拓扑生成；错误拓扑仅作为模型接收到的观测上下文。

不能使用错误拓扑重新生成物理监督签名，否则无法判断模型是在恢复真实物理关系，还是在拟合错误拓扑所产生的响应。

### 4.4 S1 可靠性判据

S1 应同时保留候选残差和拓扑扰动信息。除报告故障检测、Top-1、Top-K、真实候选排名和无故障误报率外，还应观察：

- 错误拓扑下是否出现所有候选残差同步升高；
- 少量拓扑修正是否能使残差整体下降；
- 修正后的候选排序是否在不同时间窗口和同一样本的多种拓扑视图下保持稳定；
- 模型能否将“无法解释”与“拓扑可能错误”区分开。

## 五、S2：部分观测场景

### 5.1 实验目的

S2 模拟量测系统不完整、关键节点以外观测缺失和随机节点掉线等情况。其核心问题是：观测不足时，模型是否仍然能够保持合理的候选排序，并避免将“缺少异常证据”误判为“无故障”或某一具体故障。

### 5.2 观测方案与比例

S2 包含三种观测方案：

- 全观测；
- 关键节点观测；
- 随机稀疏观测。

随机稀疏观测率设置为 10%、30%、50% 和 70%。正式实施前必须明确这些数值表示观测保留率还是观测缺失率，并在数据元数据和实验报告中保持一致。

### 5.3 数据处理原则

部分观测样本保留完整物理签名作为监督目标，同时保存实际可观测节点和时间点的掩码。训练目标与推理比较范围应明确区分：完整签名用于物理监督，实际观测范围用于观测一致性评价。

正常样本也必须进行部分观测增广，分别评价故障召回率和无故障误报率。

## 六、S3：跨拓扑泛化场景

### 6.1 实验目的

S3 用于检验模型是否真正学习了与故障物理机制相关的可迁移规律，而不是记忆训练拓扑的节点编号、邻接关系、线路数量或馈线规模。

### 6.2 拓扑变体

训练集包含多个拓扑变体，测试集使用训练阶段未出现的拓扑变体。变体生成基于 IEEE 33 节点和 IEEE 123 节点系统，包括：

- 开关重构；
- 随机删线路；
- 随机加线路。

随机删加线路后必须进行物理可行性校验，包括连通性、辐射状或允许的弱环网结构、电压约束和潮流可行性。

### 6.3 数据划分原则

训练集与测试集按拓扑实例或拓扑族划分，不能仅按时间窗口或随机样本划分。来自同一拓扑的相邻运行工况不能被分别视为已见拓扑和未见拓扑。

### 6.4 评价重点

S3 按测试拓扑分别报告故障检测、定位、Top-K、正常误报和候选排名，并同时给出拓扑间均值与最差拓扑结果。正式结论不能只依赖所有拓扑混合后的平均值。

## 七、S4：高阻故障场景

### 7.1 实验目的

S4 用于检验故障响应减弱时的可检测性和可定位性。高阻故障可能产生较小的电压变化，使错误候选与真实候选的 residual 差异更小，也增加与无故障样本混淆的风险。

### 7.2 阻抗档位

故障阻抗采用低阻、中阻和高阻多档均衡采样。场景定义中给出的高阻示例为 (z_{fault}\ge100\Omega)。正式实验需明确三档阻抗的数值范围和样本配额。

### 7.3 组合方式

S4 应作为其他场景的附加条件，至少形成：

- S0 + S4；
- S1 + S4；
- S2 + S4；
- S3 + S4。

高阻样本应按阻抗档位、故障类型、运行工况和拓扑条件分层统计，不能只报告一个总体平均值。

## 八、统一评价框架

S1–S4 均应从以下方面进行评价：

- 故障检测：准确率、故障召回率、F1、ROC-AUC 和无故障误报率；
- 候选定位：Top-1、Top-K、真实候选平均排名和残差间隔；
- 物理解释：真实候选与反事实候选的签名误差及残差排序；
- 鲁棒性：相对于 S0 的性能下降，以及不同扰动强度下的下降曲线；
- 稳定性：同一物理样本不同拓扑或观测视图之间的预测一致性；
- 失效识别：模型无法解释当前样本时是否能够降低置信度，而不是强行输出确定性结果。

每个测试样本应保留场景类型、错误率或观测率、拓扑标识、阻抗档位、故障类型、运行工况、候选残差、真实候选排名和无故障残差等信息，以支持分层分析。

## 九、总体实验逻辑

S1–S4 共同构成从理想条件到复杂条件的可靠性压力测试：

```text
S0：正确拓扑、全量观测
  → S1：拓扑上下文污染
  → S2：观测证据减少
  → S3：网络结构变化
  → S4：故障物理信号减弱
```

四类场景的最终目标不是单纯提高平均准确率，而是验证模型是否能够在信息受到污染或物理差异变弱时，继续提供稳定、可比较、可解释的故障候选判断，并在证据不足时识别自身失效风险。

## 十、实施前需固定的事项

- S1 错误率的分母与取整规则；
- S1 缺失状态的统一数据表示；
- S2 观测率与缺失率的语义；
- S3 拓扑实例和拓扑族的训练测试划分；
- S4 三档故障阻抗的具体范围；
- 各场景组合实验的样本比例；
- 各场景的正式验收指标和允许的性能下降范围。
