# Method-A1 新投影空间：发现目的与成立前提

**研究讨论记录**

**文档范围：**本文仅记录当前关于“为什么需要寻找新的投影/表示空间 Z”以及“该空间若用于故障根因判别，需要满足哪些前提”的已形成认识。本文不确定 Z 的具体构造方式，不讨论具体编码器、解码器、损失函数或物理算子实现。

**状态说明：**以下内容属于对 Method-A1 后续研究方向的工作定义与成立条件，不等同于当前已批准的 S0 实现。

# 一、为什么需要寻找新的投影空间

## 1. 当前 Method-A1 的基本诊断逻辑

当前 Method-A1 对每个候选故障假设生成对应的反事实物理签名，并通过该候选签名与实际观测之间的残差完成根因比较。

S_k = Ψ(G, do(F = k), H)

其中，**candidate（候选）**指推理时需要进行反事实检验的一个可能故障假设。当前母线级 S0 中，k∈{0,…,N−1} 表示“故障发生在第 k 个候选母线”，NO_FAULT 表示“当前系统不存在故障”。candidate 不是普通类别标签，而是一个具有明确干预含义的故障假设。

r_S(k) = d_S(S_k, X)

k̂ = arg min_k r_S(k)

因此，当前 A1 的根因判定原则是：哪个候选故障对应的反事实物理响应与当前实际观测最一致，哪个候选就具有更强的根因解释能力。

## 2. 当前问题不是物理签名不可分，而是困难候选的物理分离裕度过小

Oracle physical separability 诊断表明：直接使用真实 OpenDSS 反事实签名进行候选 residual 排序时，当前测试条件下 Oracle Top-1 可达到 100%。这说明真实物理签名中确实存在足以识别根因的信息。

**hardest negative candidate** 定义为：在所有错误候选中，与真实观测的 Oracle residual 最小、因而最容易与真实候选混淆的那个候选。

j\* = arg min\_{j ≠ k_true} r_oracle(j)

**hardest-negative physical gap** 定义为真实候选与该最危险错误候选之间的 Oracle residual 差：

Δ_hard = r_oracle(j\*) − r_oracle(k_true)

它表示：在真实物理签名完全准确的情况下，真实故障候选相对于最容易混淆的错误候选，天然拥有多大的 residual 分离裕度。该值越小，说明两个候选虽然仍然可以被物理上区分，但区分所依赖的差异越细微。

当前诊断中，hardest-negative physical gap 的中位数量级约为 2.04×10⁻⁴。因此当前矛盾不是“物理上不存在区分信息”，而是“真实区分信息存在，但部分困难候选的分离裕度非常小”。

模型预测误差尺度 \> 困难候选之间的真实物理分离尺度

当模型预测误差大于这种微小分离裕度时，即使真实 OpenDSS signature 的候选排序是正确的，模型预测后的 residual 排序仍可能发生反转。因此，需要探索一个更适合模型预测与候选比较的表示空间。

## 3. 寻找新空间的根本目标

新投影空间的目标不是创造新的故障信息，而是重新表达原物理 signature 中已经存在、但在当前坐标或度量下不够显著的判别信息。

**目标一：提高候选的可分辨性。** 真实候选与最危险错误候选在新空间中应具有更可靠的诊断裕度，尤其要改善困难候选，而不是只提高所有候选之间的平均距离。

**目标二：提高可预测性。** 新空间不能只让真实候选彼此距离变大，还必须使 Method-A1 的候选条件预测器能够更稳定、更准确地预测对应表示。

**目标三：提高“分离裕度 / 预测误差”比。** 真正决定定位是否稳定的，不是新空间中的绝对距离，而是模型预测误差相对于最近竞争候选间隔的大小。

ρ_Z(k) = e_Z(k) / δ_Z(k)

其中 δ_Z(k) 表示真实候选 k 与最近错误候选在 Z 空间中的真实分离裕度，e_Z(k) 表示模型对该候选表示的预测误差。理想状态是 ρ_Z(k) 显著小于当前 S 空间中的对应比例。

**目标四：发现适合根因判别的空间，而不是单纯寻找高维空间。** Z 的维度高低不是目的。真正要寻找的是一种表示结构或诊断几何，使真实物理信息更容易被模型预测，并更适合区分故障候选。

# 二、新投影空间不能人为创造故障信息

## 1. 新空间中的判别信息必须来源于真实物理信息

设 T:S→Z 为从原物理签名空间到新空间的表示映射。若两个候选在真实物理 signature 上完全一致，即 S_i=S_j，则任何只使用这些物理信息的确定性映射都应满足 T(S_i)=T(S_j)。

因此，新空间所谓“扩大区分度”只能是重新组织、重新加权或突出 S 中已经存在的微弱差异，不能通过 candidate ID 或其他旁路信息为不同候选凭空附加可分辨编码。

如果 Z 的可分性主要来自候选编号，而不是候选对应的真实反事实响应，那么 Z 就退化为普通分类表示，不再是在重新表达 Method-A1 的物理 signature。

## 2. 好的 Z 不能只追求真实候选之间的距离变大

一个空间即使能显著放大不同候选的真实距离，也未必适合 Method-A1。若这种空间同时使模型预测误差放大得更多，则根因定位仍可能恶化。

δ_Z(k) = min\_{j ≠ k} d_Z(z_k, z_j)

e_Z(k) = d_Z(ẑ\_k, z_k)

ρ_Z(k) = e_Z(k) / δ_Z(k)

因此，寻找 Z 的评价核心应从“候选之间距离是否更大”转向“在模型可达到的预测精度下，候选是否更稳定地可分”。

# 三、Z 空间的两条基本作用路线

寻找 Z 以后，仍需明确故障根因最终在哪个空间确定。目前保留两条本质不同的路线。

## 1. 路线一：在 Z 空间直接进行根因判别

z_obs = T(X), r_Z(k) = d_Z(ẑ\_k, z_obs), k̂ = arg min_k r_Z(k)

在该路线中，Z 是最终诊断空间。新空间不仅改变模型的学习目标，也改变候选根因的评分方式。其直接优势是可以真正利用 Z 中被改善的候选判别裕度。

## 2. 路线二：在 Z 空间学习，在 S 空间进行根因判别

ẑ\_k → Ŝ\_k, r_S(k) = d_S(Ŝ\_k, X), k̂ = arg min_k r_S(k)

在该路线中，Z 只作为新的学习/中间表示空间；最终根因仍由原物理空间 S 中的 residual 决定。因此该路线是否有效，取决于 Z 是否能显著提高最终 S signature 的预测精度。

**当前讨论重点：**优先探讨路线一的成立前提，即 Z 是否有资格直接替代 S 成为根因诊断空间。

# 四、路线一成立的前提

## 1. Z 空间距离必须能够作为根因评分

如果最终采用 r_Z(k)=d_Z(ẑ\_k,z_obs) 判断根因，则 Z 空间中的距离必须能够反映候选故障假设对当前观测的解释程度。仅仅让不同 candidate 在 Z 中分得更开，并不足以说明距离最小的 candidate 就是真实根因。

## 2. Z 必须保持真实物理 Oracle 的根因正确性

k_true = arg min_k d_Z(T(S_k), T(X))

在真实物理 signature 条件下，映射到 Z 以后，真实 candidate 仍必须是最优 candidate。Z 可以改变各候选之间的距离大小，但不应把原本正确的 Oracle 根因改变成错误根因。

## 3. Z 必须真正改善“候选分离裕度 / 模型预测误差”

如果新空间只放大 candidate separation，同时也以相同或更大的比例放大模型预测误差，则其诊断价值并没有提高。因此应比较 Z 与 S 中的相对可辨识性，而不是只比较绝对距离。

要求：ρ_Z \< ρ_S（尤其对困难候选）

## 4. Candidate 与 Observation 必须处于同一个诊断空间

候选表示 z_k=T(S_k) 与观测表示 z_obs=T(X) 必须服从同一空间定义、同一坐标语义和同一距离规则。否则 d_Z(ẑ\_k,z_obs) 不具有统一可比较的含义。

## 5. Z 中的判别能力必须来源于 S 中真实存在的信息

新空间可以突出原 signature 中细微但真实的候选差异，但不能利用 candidate ID 等额外旁路信息制造虚假 separation。这是路线一保持反事实诊断语义的基本边界。

## 6. 应重点改善困难候选，而不是平均 pairwise distance

当前定位错误主要由最容易与真实候选竞争的少数候选决定，因此评价 Z 时，应重点考察真实候选与最近错误候选之间的最小诊断裕度。平均 pairwise distance 增大并不能自动说明根因定位能力提高。

# 五、当前结论与未决问题

**当前已经明确：**寻找 Z 的目的不是设计一个新的编码器本身，也不是人为把不同故障候选拉远，而是寻找一个更适合 Method-A1 候选表示预测与根因比较的诊断空间。

**当前优先研究问题：**路线一能否成立，即是否存在一个 Z，使其在保持真实 Oracle 根因正确性的同时，显著提高困难候选的“分离裕度 / 预测误差”比。

**尚未确定，本文不作结论的事项：**Z 的具体构造方式；是否需要显式编码器/解码器；映射是否必须严格可逆；采用何种度量；采用何种训练损失；以及最终是否批准路线一替代当前 S 空间 residual 诊断。
