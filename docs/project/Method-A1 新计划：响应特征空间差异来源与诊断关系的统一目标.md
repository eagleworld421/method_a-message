# Method-A1 新计划：响应特征空间差异来源与诊断关系的统一目标

## 一、总体目标

在已有物理响应特征空间的基础上构建新的诊断表示空间，使其满足以下要求：

1. 原始响应特征中已有的故障信息得到充分保留和有效强化；
2. 与诊断无关的背景变化不会主导样本间距离或诊断决策；
3. 与故障表现有关的工况信息得到合理利用，而不是被简单删除；
4. 具有可辨识基础的故障候选形成稳定、有效的区分关系；
5. 新空间保持经过验证的物理约束关系。

整体目标为：

> 在保持经验证物理约束的前提下，强化已有故障信息的诊断表达，抑制无关因素的干扰，并构建适合故障判别的诊断关系。

### 1.1 验证前置协议

在执行任何问题验证和方法比较前，应固定：

- 故障变量、工况变量、观测变量、干扰变量及其交互项的定义；
- 按基础样本、运行工况和拓扑实例分组的数据划分，禁止派生视图跨集合泄漏；
- Oracle、预测误差、physical gap、`rho`、候选错序率、检测、校准和拒识指标；
- 噪声、重复仿真误差和数值误差的估计方法；
- identity、random、label-shuffle、candidate permutation 和 predictor-only 对照；
- 随机种子、置信区间、成功阈值和停止条件。

后续任何方法不得单独修改上述协议，以避免因评价条件变化产生虚假改善。

## 二、Step 1：验证故障信息是否充分并高于噪声边界

### 2.1 需要检验的问题

在讨论因素处理和诊断几何之前，应首先判断现有观测是否包含足以区分目标故障的信息。该判断应基于条件分布：

```math
p(S\mid F,C,O),
```

其中 $F$ 表示故障，$C$ 表示真实运行工况，$O$ 表示观测条件。仅比较 $p(S\mid F)$ 可能把工况或观测分布差异误认为故障信息。

需要检验：

- 不同故障候选的真实物理响应是否可由 Oracle 稳定区分；
- hardest-negative physical gap 是否显著高于测量噪声、数值误差和重复仿真误差；
- 可分性是否在不同故障类型、阻抗、工况、观测率和拓扑条件下保持；
- 是否存在不可分、近似并列或只能输出候选集合的故障对。

### 2.2 不可辨识边界

如果在给定工况和观测条件下满足：

```math
p(S\mid F_1,C,O)=p(S\mid F_2,C,O),
```

则任何仅依赖 $S$ 的确定性映射 $Z=f(S)$ 都无法真正区分 $F_1$ 与 $F_2$。

如果两个分布并非完全相等，但其差异小于噪声和误差水平，也不能据此宣称信息在实际诊断中充分。此时应考虑：

- 增加传感信息或时间信息；
- 改变可控运行条件；
- 调整候选粒度或合并不可区分类别；
- 输出候选集合、不确定性或拒识结果；
- 在有物理依据时增加观测或推断先验。

不能通过增大网络容量或强制拉开表示距离来制造当前观测中不存在的信息。

### 2.3 需要建立的证据

至少报告：

- Oracle Top-1、Top-K 和候选错序率；
- hardest-negative physical gap 的中位数、低分位数和最小值；
- physical gap 相对于噪声和误差水平的比例；
- 不可分候选对、并列候选对及其适用条件；
- 按故障类型、阻抗、工况、观测率和拓扑分层的置信区间。

本步骤对应命题 H0 和实验 `E0-Oracle 信息充分性与噪声边界实验`。S2 和 S4 还必须分别通过其专门的 Oracle 实验验证，不能由 S0 结果外推。

### 2.4 条件性结论

- 如果真实物理响应不可分，则问题属于信息不足，不进入表示几何优化；
- 如果真实物理响应可分但 physical gap 被噪声覆盖，则优先处理观测、去噪和不确定性；
- 只有当真实故障信息存在、达到实际可利用量级并具有明确适用范围时，才继续审计多因素影响和诊断瓶颈。

### 2.5 本步结论

> 先确认故障信息真实存在、具有条件可辨识性且高于噪声边界，再讨论如何处理多因素混合和构建诊断表示。

## 三、Step 2：验证原始响应特征距离是否混合了故障、工况及其他因素的影响

### 3.1 需要验证的问题

对于物理响应特征之间的差异

```math
\Delta S_{ij}=S_i-S_j,
```

其来源可能包括：

- 故障类型或故障程度变化；
- 运行状态变化；
- 负荷变化；
- 环境变化；
- 测量噪声；
- 其他背景因素变化；
- 故障与工况之间的交互作用。

因此，可以将响应特征差异的生成关系概念性地表示为：

```math
\Delta S
=
G(\Delta F,\Delta C,\Delta O,\Delta N,
\Delta F\!\times\!\Delta C,\varepsilon).
```

其中：

- $\Delta F$ 表示故障状态变化；
- $\Delta C$ 表示解释故障响应时需要保留的工况变化；
- $\Delta O$ 表示观测条件变化；
- $\Delta N$ 表示与诊断目标无关的背景变化；
- $\Delta F\!\times\!\Delta C$ 表示故障与工况交互；
- $\varepsilon$ 表示测量误差和随机扰动。

上述关系仅用于提出待验证的差异来源，不预设系统线性可加，也不预设各因素已经能够被唯一识别。

### 3.2 需要建立的证据

不能仅凭“可能存在多种因素”就认定原始距离无效，而应检验：

- 相同故障跨工况距离相对于同工况跨故障距离是否过大；
- 工况变化是否会改变故障候选排序或 hardest-negative；
- 不同故障是否在控制工况和观测条件后仍发生距离混淆；
- 原始距离是否主要受到负荷、环境或其他非目标因素影响；
- 原始邻域和距离排序是否能够稳定反映故障关系；
- 这些现象是否能够在不同数据划分和运行环境中重复出现。

### 3.3 条件性结论

如果上述现象显著存在，则说明原始响应特征距离

```math
d_S(S_i,S_j)
```

不能被直接解释为纯粹的故障差异。

这并不意味着原始距离完全没有诊断价值，而是说明它可能同时包含故障信息、工况信息和无关干扰，因而需要进一步处理。

如果非故障因素对距离和候选排序的影响可以忽略，也不能据此直接断言“表示空间没有问题”。该结果只说明无须优先处理多因素混合；仍应在 Step 5 中检验预测器、校准与距离结构是否构成独立瓶颈。

### 3.4 本步结论

> 首先验证原始响应特征距离是否受到故障、工况及其他因素的共同影响，避免将所有物理差异直接等同于故障差异。

## 四、Step 3：判断非故障因素的作用并明确诊断表示目标

原始响应特征空间存在混合差异时，诊断表示的目标不应仅表述为降低非故障因素的影响，而应同时包括故障信息强化与无关干扰抑制。

### 4.1 强化故障信息的诊断表达

对于原始响应特征中已经存在的故障信息，需要：

- 提高其在诊断决策中的相对贡献；
- 聚合分散在不同维度中的弱故障信号；
- 提高故障信号相对于噪声和背景变化的显著程度；
- 使故障相关变化形成更加稳定的判别依据。

如果

```math
Z=f(S)
```

只是对原始响应特征的确定性变换，那么它不能凭空创造原始数据中不存在的故障信息。因此，“强化故障信息”主要是提高已有故障信息的可利用性、可辨识性和相对显著性，而不是无条件增加故障信息总量。

### 4.2 抑制无关因素的干扰

对于与诊断目标无关的变化，需要降低其对以下对象的影响：

- 样本间距离；
- 邻域结构；
- 故障候选排序；
- 最终诊断决策。

但并非所有非故障变量都应被删除。例如，负荷本身可能不是故障，却可能决定故障信号的表现形式。此时应在给定负荷条件下识别故障，而不是要求诊断表示完全忽略负荷。

因此，需要区分：

- 应当抑制的无关干扰因素；
- 应当作为条件变量保留的运行工况；
- 应当显式建模的故障与工况交互因素。

### 4.3 综合目标

诊断表示的概念性目标可以表示为：

```math
\max_f
\quad
\mathcal D_F(Z)
-
\lambda\mathcal S_N(Z),
\qquad Z=f(S),
```

其中：

- $\mathcal D_F(Z)$ 表示故障信息的可辨识性；
- $\mathcal S_N(Z)$ 表示诊断表示对无关因素的敏感程度；
- $\lambda$ 表示故障表达强化与干扰抑制之间的权衡。

### 4.4 本步结论

> 新空间既要强化已有故障信息的诊断表达，也要抑制无关背景因素的影响，同时保留解释故障表现所必需的工况信息。

## 五、Step 4：确定显式因素识别与隐式不变表示的适用方式

### 5.1 两类解决思想

对于混合差异问题，可以采用两类不同但不互斥的解决思想。

第一类是显式因素识别，即尝试解释哪些变化来自故障、工况或背景因素。该方向强调差异来源的可解释性和物理意义。

第二类是隐式不变表示学习，即不要求恢复每个真实生成因素，而是学习一个对故障信息充分、对无关干扰不敏感的诊断表示。

因此：

```math
\text{抑制干扰}
\not\Rightarrow
\text{必须显式分解全部因素}.
```

### 5.2 显式因素识别的适用条件

如果研究目标要求：

- 解释诊断依据；
- 证明模型使用了真实故障机制；
- 分析故障与工况的交互关系；
- 支持跨工况或跨设备迁移；
- 排除特定伪相关因素；

则显式因素识别具有较强必要性。

但是，仅凭观测相关性、单一因素标签或多环境数据本身，不能保证恢复真实的故障来源。显式来源识别通常需要故障与工况具有独立或交叉变化，并结合以下一种或多种额外条件：

- 故障与工况能够独立或交叉变化；
- 存在多工况、多环境数据；
- 存在干预数据；
- 存在工况或背景因素标签；
- 存在可信物理模型；
- 存在足够明确的结构假设。

如果故障与某个背景因素在数据中始终共同变化，则无法仅凭数据确定模型利用的是故障机制还是背景相关性。

即使模型能够从只有 $S$ 和 $F$ 的数据中学习到有用潜变量，也不能据此声称这些潜变量唯一对应真实工况或背景因素。显式因素识别还必须通过留出工况复核、标签置换对照及必要的物理一致性检验。

### 5.3 隐式不变表示的适用条件

如果研究目标主要是获得稳定预测，并且不要求恢复全部真实生成因素，则可以优先学习对故障充分、对无关干扰不敏感的表示。

这里的不变性必须具有明确对象。模型应对真正无关的干扰保持不变，而不应对所有非故障因素一律保持不变。对于会改变故障表现形式的负荷或运行状态，更适合采用条件不变表示，即在给定工况的条件下提取稳定的故障信息。

条件表示只有在推理阶段能够获得相应工况变量时才能直接实现。如果工况不可观测或测量不可靠，应采用多环境鲁棒学习、隐变量建模或不确定性输出，而不能在方法中假定真实工况始终已知。

### 5.4 组合方式

显式因素识别和隐式不变表示并非只能二选一。可根据研究条件选择：

- 仅进行显式因素识别；
- 仅学习对无关干扰不敏感的表示；
- 识别部分关键因素，并在此基础上学习条件不变表示。

### 5.5 决策规则

- 如果多因素影响可以忽略，则不引入因素分解或不变表示；
- 如果无关干扰显著且跨环境定义明确，则考虑不变表示；
- 如果工况会改变故障表现且推理阶段可以获得，则考虑条件表示；
- 如果因素具有交叉数据、干预或充分结构约束，则允许比较显式因素识别；
- 如果因素不能唯一识别但存在稳定的跨环境故障关系，则考虑隐式或部分条件不变表示；
- 如果缺少必要的因素变化与交叉覆盖，则优先补充数据，不声称已经恢复真实物理因素。

具体方法思想的最终选择仍需通过统一数据、预测器、训练预算和评价协议下的对照实验完成，不能只由上述概念条件决定。

### 5.6 本步结论

> 根据研究目标、可解释性要求和数据可辨识条件，选择显式识别变化来源、学习对无关干扰不敏感的表示，或将两种方式结合。

## 六、Step 5：归因诊断困难的主要瓶颈

### 6.1 为什么需要独立进行瓶颈归因

确认故障信息存在且候选具有一定可辨识性，只能排除“完全没有可用故障信息”的情况，不能直接证明当前性能损失来自距离结构。

即使 Oracle 候选排序正确，模型诊断失败仍可能来自：

- 有效物理分离裕度小于测量噪声或重复仿真误差；
- 响应特征预测器误差覆盖了真实候选差异；
- 检测阈值或概率校准不合理；
- 原始距离、邻域或候选排序对诊断任务不稳定；
- 上述因素之间的交互。

因此：

```math
\text{故障具有可辨识基础}
\neq
\text{诊断困难由距离结构造成}.
```

### 6.2 需要区分的瓶颈类型

至少需要区分以下五类瓶颈：

1. 信息不足：现有观测无法区分目标故障；
2. 噪声覆盖：故障信息存在，但物理分离裕度不高于噪声或数值误差；
3. 预测器瓶颈：真实响应可分，但预测误差覆盖有效差异；
4. 决策与校准瓶颈：候选得分含有有效信息，但阈值、概率校准或拒识规则不合理；
5. 距离结构瓶颈：信息与预测精度基本满足要求，但现有距离、邻域或排序仍不能稳定表达诊断关系。

### 6.3 验证路径

首先使用真实物理响应特征完成 Oracle 信息充分性与噪声边界检验，至少报告：

- Oracle Top-1、Top-K 和候选错序率；
- hardest-negative physical gap 的中位数、低分位数和最小值；
- physical gap 相对于测量噪声、数值误差和重复仿真误差的比例；
- 不可分候选对、并列候选对及其适用条件。

随后在相同数据划分、预测器初始化和训练预算下进行瓶颈归因对照：

1. 原始响应特征空间基线；
2. predictor-only：只改进预测器，不改变距离结构；
3. 固定无学习变换：标准化、白化或具有物理依据的差分表示；
4. 冻结预测器，只优化诊断空间；
5. 预测器与诊断空间联合优化；
6. identity、random、label-shuffle 和 candidate permutation 对照。

各组应同时比较：

```math
\delta=\text{真实候选相对于最难负候选的物理分离裕度},
```

```math
e=\text{响应特征预测误差},
```

```math
\rho=\frac{e}{\delta+\epsilon},
```

以及候选错序率、真实候选排名、Oracle fidelity 和跨随机种子稳定性。

本步骤对应《Method-A1 具体方法确认前证据审计与验证计划》中的命题 H4 和实验 `E4-预测器与几何瓶颈归因实验`。单次 Z 空间 Top-1 改善或单一 `R` 指标不能作为距离结构瓶颈成立的证据。

### 6.4 决策规则

- 如果 Oracle 已不可分，则判定为信息不足，不进入诊断几何优化；
- 如果 Oracle 可分但 physical gap 被噪声覆盖，则优先处理观测、去噪和不确定性；
- 如果 predictor-only 已解释主要性能改善，则优先改进预测器；
- 如果候选排序基本正确，而阈值、校准或拒识规则解释了主要失败，则优先修正决策层；
- 如果固定变换已达到相同效果，则优先采用简单且可解释的固定表示；
- 只有当冻结预测器后的诊断空间优化仍能在多个随机种子下稳定改善 `rho`、候选排序和诊断结果，显著优于 predictor-only、固定变换及零假设对照，并保持 Oracle fidelity 时，才确认存在独立的距离结构瓶颈。

### 6.5 本步结论

> 在确认故障信息具有可辨识基础后，还必须区分信息不足、噪声覆盖、预测器误差、决策校准与距离结构问题；只有独立距离结构瓶颈得到验证，才能进入诊断几何优化。

## 七、Step 6：在确认距离结构瓶颈后优化有效故障差异的诊断关系

### 7.1 适用条件

只有在前一步完成瓶颈归因，并确认以下条件后，才有充分理由进行距离或表示几何优化：

1. 原始响应特征中存在可利用的故障信息；
2. 目标故障在现有观测条件下具有一定可辨识性；
3. 对照实验确认当前诊断困难至少部分来自独立的距离结构瓶颈；
4. 诊断方法确实需要依赖距离、邻域或候选排序。

### 7.2 需要解决的问题

对于映射后的表示

```math
Z_i=f(S_i),
```

需要使距离

```math
d_Z(Z_i,Z_j)
```

更加符合故障判别要求，例如：

- 同类故障在合理工况变化下保持稳定；
- 不同且可辨识的故障形成足够区分；
- 局部邻域具有稳定的故障语义；
- 候选排序对噪声和工况变化不敏感；
- 距离能够反映故障相似程度或诊断混淆程度。

### 7.3 方法方向

方法复杂度应由瓶颈归因结果决定，并按以下优先级比较：

1. 保留原始响应特征空间，只改进预测器、阈值或候选搜索；
2. 使用标准化、白化或具有物理依据的固定差分表示；
3. 在固定方法不足且独立距离结构瓶颈成立时，再采用学习型诊断空间。

学习型方向可以包括：

- 度量学习；
- 对比表示学习；
- 条件度量学习；
- 原型表示学习；
- 概率距离或分布距离建模；
- 带不确定性的候选排序。

这里的目标不是无条件增大不同类别之间的距离，也不是默认必须学习新的表示，而是在超过 predictor-only、固定变换及零假设对照后，建立与实际诊断决策相匹配的关系。

### 7.4 条件性结论

如果诊断性能确实受到距离结构限制，则需要在有效故障信息的基础上优化诊断几何。

如果问题主要来自信息不足、类别天然重叠或概率校准不良，则应采用其他方法，而不能把距离优化视为唯一解决方案。

### 7.5 本步结论

> 在确认故障具有可辨识基础且诊断受到距离结构限制后，再重新组织有效故障差异之间的关系。

---

## 八、Step 7：以经过验证的物理关系约束诊断空间优化

### 8.1 需要避免的问题

新的表示空间不能只追求训练集上的类别分离，因为模型可能：

- 放大偶然相关性；
- 扭曲真实的故障连续变化；
- 破坏故障严重程度顺序；
- 把物理上相近的状态强行分离；
- 形成训练集有效但跨工况失效的几何结构。

但是，物理响应特征由物理量构成，并不意味着其中所有距离和排序都天然可信。因此，不能笼统要求保持原始空间的全部几何关系。

### 8.2 需要作为约束保留的关系

在训练诊断空间之前，应首先通过物理知识、理论分析或独立实验确定哪些关系可信。以下内容只能作为待验证候选，不能因符合直觉就直接写入损失函数：

- 已知故障演化顺序；
- 故障严重程度的单调关系；
- 已验证的局部邻域关系；
- 物理上不应被颠倒的候选排序；
- 守恒关系、边界条件或控制方程；
- 特定工况下成立的物理相似性；
- 已知故障机制之间的层级或拓扑关系。

### 8.3 可以调整的关系

以下关系不应仅因存在于原空间中就被无条件保持：

- 主要由量纲或尺度造成的距离；
- 由负荷差异主导的邻域；
- 受噪声影响的不稳定排序；
- 未经验证的全局欧氏几何关系；
- 与诊断目标无关的背景相似性。

### 8.4 约束形式

诊断空间优化可以概念性地表示为：

```math
\min_f
\quad
\mathcal L_{\mathrm{diag}}
+
\alpha\mathcal L_{\mathrm{physical}}
+
\beta\mathcal L_{\mathrm{stability}},
```

其中：

- $\mathcal L_{\mathrm{diag}}$ 保证故障判别能力；
- $\mathcal L_{\mathrm{physical}}$ 保持经过验证的物理约束关系；
- $\mathcal L_{\mathrm{stability}}$ 限制模型对噪声和环境变化的敏感性；
- $\alpha$ 和 $\beta$ 控制诊断性能、物理一致性与稳定性之间的权衡。

### 8.5 条件性结论

诊断空间不是完全自由的几何变换，但也不应机械复制原始空间的全部距离关系。它应保留经过验证的物理约束关系，修正受到干扰的几何关系，并允许故障相关信息获得更清晰的诊断表达。

### 8.6 本步结论

> 以经过验证的物理关系约束诊断空间优化，避免将原始空间中未经验证的距离和排序直接视为必须保持的物理规律。

---

## 九、Step 8：根据验证结果确定最小方法能力

经过前述检验，候选方法可能需要具备以下能力，但不预设三类能力必须同时由一个复杂模型实现。应选择能够通过相应决策门的最小方法组合。

### 9.1 故障信息强化与干扰控制

该能力解决：

```math
\text{哪些信息应当被突出、保留、条件化或抑制？}
```

具体包括：

- 强化已有故障信息的表达；
- 抑制真正无关的背景干扰；
- 保留解释故障响应所需的工况信息；
- 建模故障与工况之间的交互；
- 在必要且可辨识时识别差异来源。

对应方向包括：

- 因素分解；
- 解耦表示；
- 因果表示；
- 条件不变表示学习；
- 多环境表示学习；
- 物理引导的特征提取。

### 9.2 诊断关系构建

该能力解决：

```math
\text{可辨识的故障信息如何形成稳定、有效的诊断关系？}
```

具体包括：

- 构建具有诊断意义的距离；
- 稳定局部邻域结构；
- 改善故障候选排序；
- 提高跨工况判别稳定性；
- 对不可分候选表达合理的不确定性。

对应方向包括：

- 度量学习；
- 对比学习；
- 原型学习；
- 概率表示学习；
- 距离结构学习；
- 不确定性建模。

### 9.3 可信物理约束

该能力解决：

```math
\text{诊断优化后是否仍符合经过验证的物理关系？}
```

具体包括：

- 保持可信的故障演化关系；
- 保持必要的局部结构或候选排序；
- 满足物理方程、边界条件或单调约束；
- 防止为追求训练集分离而产生非物理结构。

对应方向包括：

- 结构保持约束；
- 物理约束表示学习；
- 排序保持约束；
- 局部拓扑保持；
- 物理一致性正则化。

### 9.4 本步结论

> 根据已验证的问题类型选择最小方法能力；未被实验确认的问题不转化为额外模型模块，诊断几何学习也不是默认组成部分。

## 十、Step 9：最终目标与验证标准

最终希望得到新的诊断表示空间：

```math
Z=f(S),
```

并满足以下要求。

### 10.1 故障信息表达充分

原始响应特征中已有的故障信息得到保留和强化，在诊断决策中的相对贡献提高。

### 10.2 无关干扰受到控制

环境、噪声及其他无关因素不会主导距离、邻域和候选排序。需要保留的工况变量则作为条件信息得到合理利用，而不是被简单删除。

### 10.3 诊断关系有效

具有真实可辨识基础的故障候选形成稳定、合理的区分关系。对于当前观测条件下无法可靠区分的候选，模型应表达不确定性，而不是强行制造类别间隔。

### 10.4 物理关系可信

新空间保持经过验证的物理规律、局部关系和故障演化结构，同时允许修正原空间中受尺度、工况和噪声支配的关系。

### 10.5 结果具有跨环境稳定性

新空间的诊断关系不仅在训练集上有效，而且能够在不同负荷、工况、设备或时间条件下保持稳定。

跨环境验证必须：

- 按运行工况、拓扑实例或拓扑族进行互斥划分；
- 禁止同一基础样本的派生视图跨训练、验证和测试集合；
- 覆盖 S1 拓扑错误、S2 部分观测、S3 跨拓扑、S4 高阻及其必要组合；
- 同时报告平均环境、最差环境、跨种子置信区间和失败样本；
- 纳入正常样本的误报、弱故障漏报、概率校准、风险—覆盖关系和拒识结果；
- 与原始空间、predictor-only、固定变换及零假设对照进行比较。

跨环境稳定性只能证明经验鲁棒性，不能单独证明因素已经被唯一识别或模型已经恢复真实物理机制。
