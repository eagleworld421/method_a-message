# Method-A1 新计划：响应特征空间差异来源与诊断关系的统一目标

## 一、总体目标

在已有物理响应特征空间的基础上构建新的诊断表示空间，使其满足以下要求：

1. 原始响应特征中已有的故障信息得到充分保留和有效强化；
2. 与诊断无关的背景变化不会主导样本间距离或诊断决策；
3. 与故障表现有关的工况信息得到合理利用，而不是被简单删除；
4. 具有可辨识基础的故障候选形成稳定、有效的区分关系；
5. 新空间保持经过验证的物理约束关系。

整体目标为：

> 在保持经验证物理约束的前提下，强化已有故障信息的诊断表达，抑制无关因素的干扰，并构建适合故障判别的诊断关系。

---

## 二、Step 1：验证原始响应特征距离是否混合了故障、工况及其他因素的影响

### 2.1 需要验证的问题

对于物理响应特征之间的差异

```math
\Delta S_{ij}=S_i-S_j,
```

其来源可能包括：

- 故障类型或故障程度变化；
- 运行状态变化；
- 负荷变化；
- 环境变化；
- 测量噪声；
- 其他背景因素变化；
- 故障与工况之间的交互作用。

因此，可以将响应特征差异概念性地表示为：

```math
\Delta S
=
\Delta S_{\mathrm{fault}}
+
\Delta S_{\mathrm{context}}
+
\Delta S_{\mathrm{nuisance}}
+
\Delta S_{\mathrm{interaction}}
+
\Delta S_{\mathrm{noise}}.
```

其中：

- $\Delta S_{\mathrm{fault}}$ 表示由故障状态引起的变化；
- $\Delta S_{\mathrm{context}}$ 表示解释故障响应时需要保留的工况变化；
- $\Delta S_{\mathrm{nuisance}}$ 表示与诊断目标无关的背景变化；
- $\Delta S_{\mathrm{interaction}}$ 表示故障与工况共同作用产生的变化；
- $\Delta S_{\mathrm{noise}}$ 表示测量误差和随机扰动。

上述分解仅用于提出待验证的差异来源，不预设各组成部分已经能够被唯一识别。

### 2.2 需要建立的证据

不能仅凭“可能存在多种因素”就认定原始距离无效，而应检验：

- 相同故障在不同工况下是否出现较大距离；
- 不同故障是否可能具有较小距离；
- 原始距离是否主要受到负荷、环境或其他非目标因素影响；
- 原始邻域和距离排序是否能够稳定反映故障关系；
- 这些现象是否能够在不同数据划分和运行环境中重复出现。

### 2.3 条件性结论

如果上述现象显著存在，则说明原始响应特征距离

```math
d_S(S_i,S_j)
```

不能被直接解释为纯粹的故障差异。

这并不意味着原始距离完全没有诊断价值，而是说明它可能同时包含故障信息、工况信息和无关干扰，因而需要进一步处理。

### 2.4 本步结论

> 首先验证原始响应特征距离是否受到故障、工况及其他因素的共同影响，避免将所有物理差异直接等同于故障差异。

## 三、Step 2：明确诊断表示的双重目标

原始响应特征空间存在混合差异时，诊断表示的目标不应仅表述为降低非故障因素的影响，而应同时包括故障信息强化与无关干扰抑制。

### 3.1 强化故障信息的诊断表达

对于原始响应特征中已经存在的故障信息，需要：

- 提高其在诊断决策中的相对贡献；
- 聚合分散在不同维度中的弱故障信号；
- 提高故障信号相对于噪声和背景变化的显著程度；
- 使故障相关变化形成更加稳定的判别依据。

如果

```math
Z=f(S)
```

只是对原始响应特征的确定性变换，那么它不能凭空创造原始数据中不存在的故障信息。因此，“强化故障信息”主要是提高已有故障信息的可利用性、可辨识性和相对显著性，而不是无条件增加故障信息总量。

### 3.2 抑制无关因素的干扰

对于与诊断目标无关的变化，需要降低其对以下对象的影响：

- 样本间距离；
- 邻域结构；
- 故障候选排序；
- 最终诊断决策。

但并非所有非故障变量都应被删除。例如，负荷本身可能不是故障，却可能决定故障信号的表现形式。此时应在给定负荷条件下识别故障，而不是要求诊断表示完全忽略负荷。

因此，需要区分：

- 应当抑制的无关干扰因素；
- 应当作为条件变量保留的运行工况；
- 应当显式建模的故障与工况交互因素。

### 3.3 综合目标

诊断表示的概念性目标可以表示为：

```math
\max_f
\quad
\mathcal D_F(Z)
-
\lambda\mathcal S_N(Z),
\qquad Z=f(S),
```

其中：

- $\mathcal D_F(Z)$ 表示故障信息的可辨识性；
- $\mathcal S_N(Z)$ 表示诊断表示对无关因素的敏感程度；
- $\lambda$ 表示故障表达强化与干扰抑制之间的权衡。

### 3.4 本步结论

> 新空间既要强化已有故障信息的诊断表达，也要抑制无关背景因素的影响，同时保留解释故障表现所必需的工况信息。

---

## 四、Step 3：确定显式因素识别与隐式不变表示的适用方式

### 4.1 两类解决思想

对于混合差异问题，可以采用两类不同但不互斥的解决思想。

第一类是显式因素识别，即尝试解释哪些变化来自故障、工况或背景因素。该方向强调差异来源的可解释性和物理意义。

第二类是隐式不变表示学习，即不要求恢复每个真实生成因素，而是学习一个对故障信息充分、对无关干扰不敏感的诊断表示。

因此：

```math
\text{抑制干扰}
\not\Rightarrow
\text{必须显式分解全部因素}.
```

### 4.2 显式因素识别的适用条件

如果研究目标要求：

- 解释诊断依据；
- 证明模型使用了真实故障机制；
- 分析故障与工况的交互关系；
- 支持跨工况或跨设备迁移；
- 排除特定伪相关因素；

则显式因素识别具有较强必要性。

但是，仅凭观测相关性通常不能保证恢复真实的故障来源。来源识别还需要至少一种额外条件，例如：

- 故障与工况能够独立或交叉变化；
- 存在多工况、多环境数据；
- 存在干预数据；
- 存在工况或背景因素标签；
- 存在可信物理模型；
- 存在足够明确的结构假设。

如果故障与某个背景因素在数据中始终共同变化，则无法仅凭数据确定模型利用的是故障机制还是背景相关性。

### 4.3 隐式不变表示的适用条件

如果研究目标主要是获得稳定预测，并且不要求恢复全部真实生成因素，则可以优先学习对故障充分、对无关干扰不敏感的表示。

这里的不变性必须具有明确对象。模型应对真正无关的干扰保持不变，而不应对所有非故障因素一律保持不变。对于会改变故障表现形式的负荷或运行状态，更适合采用条件不变表示，即在给定工况的条件下提取稳定的故障信息。

### 4.4 组合方式

显式因素识别和隐式不变表示并非只能二选一。可根据研究条件选择：

- 仅进行显式因素识别；
- 仅学习对无关干扰不敏感的表示；
- 识别部分关键因素，并在此基础上学习条件不变表示。

### 4.5 本步结论

> 根据研究目标、可解释性要求和数据可辨识条件，选择显式识别变化来源、学习对无关干扰不敏感的表示，或将两种方式结合。

## 五、Step 4：检验故障信息是否充分且可辨识

### 5.1 需要检验的问题

即使已经得到故障相关表示，诊断仍可能存在以下问题：

- 不同故障候选的响应高度相似；
- 同一故障在不同工况下变化较大；
- 不同故障的观测分布发生重叠；
- 有效故障信号弱于测量噪声；
- 模型预测误差覆盖有效差异；
- 现有传感器未记录区分故障所需的信息。

因此：

```math
\text{表示中存在故障信息}
\neq
\text{故障一定能够被稳定区分}.
```

### 5.2 不可辨识边界

如果两个故障在现有观测条件下满足：

```math
p(S\mid F_1)=p(S\mid F_2),
```

那么任何仅依赖 $S$ 的确定性映射 $Z=f(S)$ 都无法真正区分它们。

此时需要考虑：

- 引入新的传感信息；
- 增加时间序列信息；
- 改变观测工况；
- 引入物理先验；
- 输出不确定性或候选集合；
- 合并在当前观测条件下不可区分的故障类别。

不能仅通过人为拉大表示距离来制造不存在的可辨识信息。

### 5.3 条件性结论

在进行距离优化之前，应首先判断：

- 故障信息是否存在；
- 故障信息是否充分；
- 不同故障是否具有理论或经验上的可辨识性；
- 诊断困难究竟来自几何结构、信息不足还是噪声覆盖。

### 5.4 本步结论

> 在强化故障表达之后，还需要验证故障候选是否具有真实的可辨识基础，避免用几何分离掩盖信息不足。

---

## 六、Step 5：在必要时优化有效故障差异的诊断关系

### 6.1 适用条件

只有在确认以下条件后，才有充分理由进行距离或表示几何优化：

1. 原始响应特征中存在可利用的故障信息；
2. 目标故障在现有观测条件下具有一定可辨识性；
3. 当前诊断困难至少部分来自不合理或不稳定的距离结构；
4. 诊断方法确实需要依赖距离、邻域或候选排序。

### 6.2 需要解决的问题

对于映射后的表示

```math
Z_i=f(S_i),
```

需要使距离

```math
d_Z(Z_i,Z_j)
```

更加符合故障判别要求，例如：

- 同类故障在合理工况变化下保持稳定；
- 不同且可辨识的故障形成足够区分；
- 局部邻域具有稳定的故障语义；
- 候选排序对噪声和工况变化不敏感；
- 距离能够反映故障相似程度或诊断混淆程度。

### 6.3 方法方向

可根据任务需要选择：

- 度量学习；
- 对比表示学习；
- 条件度量学习；
- 原型表示学习；
- 概率距离或分布距离建模；
- 带不确定性的候选排序。

这里的目标不是无条件增大不同类别之间的距离，而是建立与实际诊断决策相匹配的关系。

### 6.4 条件性结论

如果诊断性能确实受到距离结构限制，则需要在有效故障信息的基础上优化诊断几何。

如果问题主要来自信息不足、类别天然重叠或概率校准不良，则应采用其他方法，而不能把距离优化视为唯一解决方案。

### 6.5 本步结论

> 在确认故障具有可辨识基础且诊断受到距离结构限制后，再重新组织有效故障差异之间的关系。

---

## 七、Step 6：以经过验证的物理关系约束诊断空间优化

### 7.1 需要避免的问题

新的表示空间不能只追求训练集上的类别分离，因为模型可能：

- 放大偶然相关性；
- 扭曲真实的故障连续变化；
- 破坏故障严重程度顺序；
- 把物理上相近的状态强行分离；
- 形成训练集有效但跨工况失效的几何结构。

但是，物理响应特征由物理量构成，并不意味着其中所有距离和排序都天然可信。因此，不能笼统要求保持原始空间的全部几何关系。

### 7.2 需要作为约束保留的关系

应首先通过物理知识、理论分析或实验数据确定哪些关系可信，例如：

- 已知故障演化顺序；
- 故障严重程度的单调关系；
- 已验证的局部邻域关系；
- 物理上不应被颠倒的候选排序；
- 守恒关系、边界条件或控制方程；
- 特定工况下成立的物理相似性；
- 已知故障机制之间的层级或拓扑关系。

### 7.3 可以调整的关系

以下关系不应仅因存在于原空间中就被无条件保持：

- 主要由量纲或尺度造成的距离；
- 由负荷差异主导的邻域；
- 受噪声影响的不稳定排序；
- 未经验证的全局欧氏几何关系；
- 与诊断目标无关的背景相似性。

### 7.4 约束形式

诊断空间优化可以概念性地表示为：

```math
\min_f
\quad
\mathcal L_{\mathrm{diag}}
+
\alpha\mathcal L_{\mathrm{physical}}
+
\beta\mathcal L_{\mathrm{stability}},
```

其中：

- $\mathcal L_{\mathrm{diag}}$ 保证故障判别能力；
- $\mathcal L_{\mathrm{physical}}$ 保持经过验证的物理约束关系；
- $\mathcal L_{\mathrm{stability}}$ 限制模型对噪声和环境变化的敏感性；
- $\alpha$ 和 $\beta$ 控制诊断性能、物理一致性与稳定性之间的权衡。

### 7.5 条件性结论

诊断空间不是完全自由的几何变换，但也不应机械复制原始空间的全部距离关系。它应保留经过验证的物理约束关系，修正受到干扰的几何关系，并允许故障相关信息获得更清晰的诊断表达。

### 7.6 本步结论

> 以经过验证的物理关系约束诊断空间优化，避免将原始空间中未经验证的距离和排序直接视为必须保持的物理规律。

## 八、Step 7：确定方法能力

经过前述检验，新方法可能需要具备三个相互配合的能力。

### 8.1 故障信息强化与干扰控制

该能力解决：

```math
\text{哪些信息应当被突出、保留、条件化或抑制？}
```

具体包括：

- 强化已有故障信息的表达；
- 抑制真正无关的背景干扰；
- 保留解释故障响应所需的工况信息；
- 建模故障与工况之间的交互；
- 在必要且可辨识时识别差异来源。

对应方向包括：

- 因素分解；
- 解耦表示；
- 因果表示；
- 条件不变表示学习；
- 多环境表示学习；
- 物理引导的特征提取。

### 8.2 诊断关系构建

该能力解决：

```math
\text{可辨识的故障信息如何形成稳定、有效的诊断关系？}
```

具体包括：

- 构建具有诊断意义的距离；
- 稳定局部邻域结构；
- 改善故障候选排序；
- 提高跨工况判别稳定性；
- 对不可分候选表达合理的不确定性。

对应方向包括：

- 度量学习；
- 对比学习；
- 原型学习；
- 概率表示学习；
- 距离结构学习；
- 不确定性建模。

### 8.3 可信物理约束

该能力解决：

```math
\text{诊断优化后是否仍符合经过验证的物理关系？}
```

具体包括：

- 保持可信的故障演化关系；
- 保持必要的局部结构或候选排序；
- 满足物理方程、边界条件或单调约束；
- 防止为追求训练集分离而产生非物理结构。

对应方向包括：

- 结构保持约束；
- 物理约束表示学习；
- 排序保持约束；
- 局部拓扑保持；
- 物理一致性正则化。

### 8.4 本步结论

> 新方法应根据实际问题，同时处理故障信息强化与干扰控制、诊断关系构建以及经过验证的物理约束关系保持。

## 九、Step 8：最终目标与验证标准

最终希望得到新的诊断表示空间：

```math
Z=f(S),
```

并满足以下要求。

### 9.1 故障信息表达充分

原始响应特征中已有的故障信息得到保留和强化，在诊断决策中的相对贡献提高。

### 9.2 无关干扰受到控制

环境、噪声及其他无关因素不会主导距离、邻域和候选排序。需要保留的工况变量则作为条件信息得到合理利用，而不是被简单删除。

### 9.3 诊断关系有效

具有真实可辨识基础的故障候选形成稳定、合理的区分关系。对于当前观测条件下无法可靠区分的候选，模型应表达不确定性，而不是强行制造类别间隔。

### 9.4 物理关系可信

新空间保持经过验证的物理规律、局部关系和故障演化结构，同时允许修正原空间中受尺度、工况和噪声支配的关系。

### 9.5 结果具有跨环境稳定性

新空间的诊断关系不仅在训练集上有效，而且能够在不同负荷、工况、设备或时间条件下保持稳定。
