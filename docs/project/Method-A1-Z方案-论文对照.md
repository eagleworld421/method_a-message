# Method-A1 新投影空间 Z：相关论文与方法对照

## 1. 检索范围与判断标准

检索重点是：是否使用物理约束或反事实信息；是否在拓扑变化和稀疏观测下保持语义；是否直接优化 hardest-negative 或预测误差与分离裕度的关系。公开研究普遍报告分类或定位准确率，较少同时验证 Oracle 排序保真度与 `ρ=e/δ`，因此不能直接视为 Method-A1 的现成方案。

## 2. 时空图神经网络故障诊断

Spatial-Temporal Recurrent GNN 用时序与图结构联合建模故障检测、分类和定位，并强调拓扑信息和泛化能力（[论文页面](https://arxiv.org/abs/2210.15177)）。其优势是与现有 TCN+GNN 边界相近；不足是通常直接预测类别或位置，没有保证候选反事实 signature 的同空间比较，也没有 Oracle Top-1 保真度和 hardest-negative `ρ` 约束。因此可作为预测器参考，不能替代 Z 映射。

“Fault Location via Deep Graph Convolutional Networks”将多母线测量与系统拓扑输入 GCN 完成故障定位（[论文](https://arxiv.org/abs/1812.09464)）。它说明拓扑感知有助于定位，但固定系统和监督分类设定与 Method-A1 的跨拓扑、反事实候选语义不同。

## 3. 拓扑识别与错误拓扑鲁棒性

Knowledge Graph + GNN 的拓扑识别工作展示了识别线路连通状态和处理拓扑变化的能力（[Frontiers 论文](https://www.frontiersin.org/journals/energy-research/articles/10.3389/fenrg.2020.613331/full)）。其优势是显式处理拓扑不确定性；不足是任务目标是拓扑识别，并未要求错误拓扑不得重新生成物理监督，也未验证故障候选 Oracle 排序。

Distribution-grid fault detection 的 GNN 泛化研究在不同拓扑上评估模型性能，并报告拓扑变化下的性能下降（[IEEE Xplore](https://ieeexplore.ieee.org/document/11204594/)）。它支持 S3 的拓扑族划分思想，但仍主要是判别式指标，不能证明某个 learned embedding 保留根因距离语义。

## 4. 弱特征、稀疏观测与高阻故障

面向光伏接入配电网弱特征的 GNN 研究在拓扑变化、低训练样本和弱测量条件下测试故障诊断（[PMC 论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12473272/)）。其优势是关注弱信号与拓扑适应；不足是多采用故障类别监督，未区分缺失值和真实零值的物理监督契约，也未将高阻条件系统地嵌入错误拓扑和部分观测组合。

## 5. 与三个方案的对应关系

方案一最接近受限 metric representation learning，但需要额外加入物理 Oracle 保真度、同映射约束和 `ρ` 验收；论文中的通用对比损失不能直接替代这些条件。

方案二与 physics-informed representation 的思想一致，但公开研究通常将物理约束用于预测或分类正则，较少证明公共状态/故障扰动分解的可辨识性。它需要最强的数据和消融证据。

方案三与差分、残差和归一化表示的常见做法相近，工程风险最低，但效果取决于 `S_ref` 的物理定义；论文结果不能证明任意参考都保持 Oracle 排序。

## 6. 论文证据的结论

现有论文支持三点：图结构和时序联合建模有助于故障诊断；拓扑变化、稀疏观测和弱信号确实是独立可靠性风险；物理或拓扑先验通常能改善泛化。

现有论文没有直接满足四个核心要求：反事实候选 signature 的统一映射、候选编号不可泄漏、Z 空间 Oracle 根因排序不被破坏、hardest-negative `ρ` 改善。因此这些论文只能提供设计启发和场景基线，不能替代 Method-A1 自身的验证闭环。

## 7. 对项目的建议

论文复现优先级应低于项目内部诊断：先实现方案三固定基线，再实现方案一受限映射；所有比较均保留 S 空间基线、Oracle 排序、hardest-negative 和分层 S1–S4 指标。方案二只有在多工况数据和参考分解得到独立证据后再进入实现。
