# Method-A1 新投影空间 Z：三个候选技术路线

## 1. 研究目标与共同边界

当前真实物理响应特征已经包含根因信息，但模型预测误差相对于 hardest-negative 的物理间隔过大。三个方案都实现同一目标：在不引入候选编号、节点编号或类别标签的前提下，将 `S∈R^{N×T×6}` 映射为更适合比较的 `Z`，并降低 `ρ=e/δ`。

共同定义为 `Eθ:S→Z`。候选响应特征、观测响应特征和预测响应特征必须共享同一组参数、同一归一化和同一距离函数。`Z` 只重组已有物理信息，不制造新的故障信息。

## 2. 方案一：受限共享逐响应特征残差映射

### 文字流程

TCN/GNN/响应特征解码器先按现有流程生成候选预测 `Ŝ_k`。随后，真实候选 `S_k`、预测候选 `Ŝ_k` 与观测 `X` 分别独立通过同一个逐响应特征编码器。编码器只读取响应特征张量，不读取候选 ID 或候选集合。最终在 Z 空间计算 masked distance 并排序。

### 形式化定义

`z=Eθ(S)=Norm(S+λgθ(S))`，其中 `gθ` 是共享的小容量残差网络，`λ` 控制变换幅度，`Norm` 是训练集固定统计量归一化。可加入 Jacobian 范数、输出输入能量比和局部 Lipschitz 正则。

定义：

`δ_Z(k)=min_{j≠k} d_Z(E(S_k),E(S_j))`；
`e_Z(k)=d_Z(E(Ŝ_k),E(S_k))`；
`ρ_Z(k)=e_Z(k)/(δ_Z(k)+ε)`。

### 数据流和边界

输入是单个完整或带掩码的物理 signature。TCN 负责时间模式，GNN 负责拓扑上下文，响应特征解码器负责从观测预测候选响应特征；Eθ 只负责坐标重组和受限重加权。它不直接输出根因。

### 优点与风险

优点是改动最小、物理语义最清晰、候选和观测共享映射，且容易回退到 S 空间。风险是容量过大时可能坍缩或放大预测误差，因此必须优先验证 `ρ_Z` 而非平均距离。

## 3. 方案二：公共运行状态与候选扰动分解

### 文字流程

先从 signature 本身估计公共运行状态成分，再得到候选特有扰动。Z 主要编码扰动，同时保留必要的公共状态信息。分解只使用响应特征统计量或物理参考，不使用候选标签。

### 形式化定义

`S=Bφ(c(S))+Pψ(S,c(S))`，其中 `c(S)` 是从响应特征估计的公共状态描述，`Bφ` 是公共成分，`Pψ` 是候选特有扰动。编码为 `E(S)=[αBφ(c), βPψ(S,c)]`。

训练包括响应特征重构损失、公共成分一致性损失和 Z 空间 masked prediction loss。分解必须在相同运行状态的候选和观测之间保持一致。

### 优点与风险

优点是可能削弱负荷、分布式电源等公共变化对候选排序的干扰，对高阻故障有潜在帮助。风险是分解不可辨识：若把真实故障扰动错误归入公共成分，就会删除根因信息；同时需要更多运行工况和消融实验。

## 4. 方案三：差分/相对 signature 表示

### 文字流程

为每个 signature 构造物理上统一的参考 `S_ref`，编码绝对 signature、相对差分和幅值统计。参考必须由明确的公共运行状态或独立基线定义，不能由候选编号或记忆表产生。

### 形式化定义

`D(S)=S-S_ref`，`E(S)=[aS,bD(S),c·Norm(D(S))]`。距离仍使用相同 masked weighted MSE。若不存在可信 `S_ref`，只能使用无参考版本作为诊断基线。

### 优点与风险

优点是实现简单、可解释，适合作为低风险对照。风险是参考误差会直接污染差分；过度去除公共成分可能损失跨工况必要信息。该方案更适合先做固定变换基线，不宜直接作为最终架构。

## 5. 统一训练与诊断闭环

路线一不能只写成“加入 Z 空间损失”。最小可执行闭环分为三个阶段：

1. **阶段 A：S 空间基线。** 使用现有 TCN/GNN/响应特征解码器，以全候选 `masked signature MSE` 训练 `fφ`，固定验证集 checkpoint，并记录 `r_S`、Oracle 排序和 hardest-negative physical gap。
2. **阶段 B：编码器预训练。** 冻结 `fφ`，以 `Eθ(S)` 和 `Eθ(X)` 的 Oracle 排序为主目标，以 `Eθ≈I` 的身份锚定、残差能量约束、Jacobian 正则和 Lipschitz 上界防止坍缩及误差放大。`gθ` 零初始化、`λ` 从 0 或小值开始。
3. **阶段 C：联合微调。** 解冻 `fφ`，同时优化 S 空间预测损失、Z 空间预测损失和 Z 空间候选排序损失。Z 目标分支使用 stop-gradient 或 EMA teacher；任何阶段都保留 S 空间损失，不能让预测器和编码器共同移动到无物理意义的坐标系。

统一写为：

```math
\mathcal L=\mathcal L_S+\alpha\mathcal L_Z
 +\beta\mathcal L_{rank-Z}+\gamma\mathcal L_{id}
 +\lambda_J\mathcal L_J+\lambda_q\mathcal L_{energy}
 +\lambda_L\mathcal L_{Lip}.
```

其中：

- `L_S` 是现有 S 空间稠密 prediction loss；
- `L_Z` 比较 `E(Ŝ)` 与 stop-gradient 的 `E(S)`；
- `L_rank-Z` 让真实候选的 `r_Z` 小于 hardest negative；
- `L_id` 约束 `E(S)` 不偏离恒等映射；
- `L_J` 约束残差分支 Jacobian；
- `L_energy` 约束输出—输入能量比处于允许区间；
- `L_Lip` 由 spectral normalization 或局部梯度上界实现。

其中 `k` 的选择遵循单独的候选契约：S0 使用母线候选 `0..N-1` 加 `NO_FAULT` 的全枚举；规模化阶段才使用“真实候选 + 全局随机 + 拓扑/电气近邻 + 当前模型困难候选”的分层候选池。物理 hardest negative 定义为完整候选集合中真实 signature residual 最小的错误候选，用于 Oracle 排序和 margin 标定；model hardest negative 定义为当前预测 residual 最小的错误候选，用于阶段 C 动态训练。两者都不能按候选编号直接指定。

最小 S0 实验必须按“输入一致性 → Oracle 保真 → `ρ_Z` → 表示稳定 → 预测收益”的顺序验收，并始终保存 S/Z 两套 residual、排名、`δ`、`e`、`ρ` 和能量统计。若 Oracle 保真或距离语义失败，路线 A 回退为 S 空间诊断；若只改善预测，则 Z 只能作为路线 B 的中间表示。

路线 A 在 Z 中直接诊断：`r_Z(k)=d_Z(E(Ŝ_k),E(X))`。路线 B 仅在 Z 作为中间表示、最终回到 S 中诊断：`ẑ_k→Ŝ_k`，`r_S(k)=d_S(Ŝ_k,X)`。研究顺序应先验证路线 A，若 Oracle 保真度或距离语义不成立，再保留路线 B。

## 6. 推荐顺序

先做方案三的固定差分基线，再做方案一的受限共享映射；方案二在多工况数据充分后再评估。每一步都必须保留 S 空间并行结果和可回退路径。
