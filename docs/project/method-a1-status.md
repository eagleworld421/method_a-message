## 5. Known Limitations and Blockers

- 当前 Oracle smoke 使用已有 IEEE13 S0 库；尚未用多个真实拓扑实例形成有效 S3 跨拓扑统计结论。
- 当前候选使用全量枚举，尚未实现分层采样、困难负样本缓存或大规模响应特征库内存映射。
- Z 路线一已实现代码闭环，但 seed 42、43、44 的 100 epoch 上限、patience 3 早停运行中 `rho_Z` 中位数均略高于 `rho_S`，`rho_Z<=rho_S` 样本比例均低于 0.15；因此当前不能宣称路线一有效，需要继续分析 margin、正则权重、阶段 C 选择规则和早停配置。
- 已完成 seed 42 的 25 组参数扫描与对照实验。identity 对照 `R=1.0`、random 对照 `R=0.919`、label-shuffle 对照 `R=0.966`，说明 R 高值可由恒等映射、随机扰动或非物理训练产生；没有配置同时满足 `Δrho>0`、`Δlog e<Δlog delta`、优于对照、Oracle 保真且绝对 `rho` 不恶化。结果详见 `docs/project/Method-A1-Z路线一-参数扫描与对照结果.md`。
- 检测阈值仍为零阈值，尚未通过验证集完成标定或不确定区间设计；Z 空间检测复用零阈值。
- E0 未指定真实传感器噪声模型；现有随机相移、故障前幅值摆动和阻尼振荡仅为未标定敏感性扰动，不能代表现场测量噪声。
- E0 风险—覆盖率曲线使用预测故障间隔与预测前两名母线间隔的较小值，不读取真实母线；但唯一母线风险容限仍需要应用侧人工给定，并须在 E7 独立数据上验证。
- E0-COV 的 CD 密度曲线在 pilot 最大测试密度处仍未完全平台化，当前以最大密度作为资源受限停止点；不得把该曲线解释为已找到最优覆盖密度。
- E0-COV 的等模板数量随机扩容对照在部分臂上产生非忽略的极值收益，说明模板数量与语义覆盖必须分开报告；语义覆盖增益的区间已在正式输出中给出。
- E1 的 H1 工况排序效应未通过；当前只能把 C0 下的跨工况翻转归因于模板覆盖，不能把局部错排关系写成训练约束。E1-C 的局部性结论必须先经 E5 独立复核。
- E4-A0/R1 的 CIS 收益仅在当前 IEEE13 全节点理想观测、测试阻抗位于开发网格范围内的条件下成立；其独立插值保真度未通过，完整候选排序一致性为 `0.0`、真实母线 rank 一致性为 `0.8978`、hardest-negative 一致性为 `0.4104`，因此不能直接解释为真实阻抗响应的忠实连续插值。
- E4-A0/R1 的 CD 未超过同规模随机阻抗扩容，CM 不作为已验证部署方案；CIS 的正式定位收益虽显著，但需受独立保真度门约束。不得把 CR/CRC 上界或旧 A0-CI 结论混入 R1 结论。
- E4-A0/R1 未包含开发网格范围外的外插样本，连续插值器在未知阻抗区间外的行为未验证；正式报告不得将 CIS 结果外推到未覆盖阻抗区间。
- E4-A0/R1 仍为 Oracle/模板诊断，只验证了未知阻抗覆盖和独立校准保真度，不含任何预测器或学习型表示证据；R1 总体为 `证据不足`，不构成 E4-A1、E4-A 或 E4-B 的预判。
- E5 pilot 只有一个 IEEE13 topology instance/family，所有距离、最近邻和 hardest-negative 结果只能作为 discovery 描述性流程证据；`formal_confirmation_allowed=false`，不得形成 H5 正式通过或候选训练约束。
- 当前 E5 签名库没有同一拓扑、工况、故障类型、候选下的至少两个阻抗档位，也没有同一候选跨至少两个 operating condition 的配对，因此阻抗单调性和跨工况排序稳定性未评估，不得按点估计补写结论。
