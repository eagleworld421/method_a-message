# Method-A1 第二阶段实验报告：全节点距离稀释局部判别差异

## 1. 实验目的与执行边界

本实验检验的命题是：**当故障位置主要改变其附近节点的响应，而远端节点的候选间差异较小或不稳定时，把所有节点等权平均到一个候选距离中，是否会稀释局部判别差异，并使候选排序 margin 变小或发生错排。**

执行边界：

- 只读取既有 `paired-v1-ieee13-640-seed342` 数据集的数组、元数据与拓扑边。
- 只加载既有 checkpoint 做一次推理，**不训练、不调参、不修改模型、不修改损失函数或评价代码**，不生成新数据。
- 逐节点距离与候选间差异量按**活跃通道数** $2K_n$ 归一。
- 真实故障标签 $c_b^\ast$ 仅用于离线分层与 `physical hardest negative` 选择，不进入部署评分。
- 排序与 margin 只在故障候选 0 至 15 上计算；索引 16 的 `NO_FAULT` 不参与定位评价。
- bootstrap 单位是事件，候选对不视为独立样本。

使用资产：

- 数据：`code/method-a1/data/pi-response/paired-v1-ieee13-640-seed342/`
- checkpoint：`code/method-a1/checkpoint/pi-response/pi-response-full-20260920-640-seed342/{student,teacher}.pt`
- student checkpoint SHA-256：`80ee01cca164b442f69891fc9c9887eea205ed3690bee0fdefac693db803aa2c`
- 主审计脚本：`code/method-a1/scripts/run_relative_response_stage2_audit.py`
- 独立复核脚本：`code/method-a1/scripts/verify_relative_response_stage2.py`

两种口径分别执行并独立成目录：

- 全样本 640 事件：`output/relative-response/stage2-audit-640-seed342-all/`
- 测试划分 96 事件：`output/relative-response/stage2-audit-640-seed342-test/`

需要说明的口径限制：全样本 640 口径包含该 checkpoint 训练所用的 448 个训练事件，其 predictor 数字含自评价成分，本报告只作并列记录，不与测试划分口径作优劣比较。

## 2. 对首版报告推理错误的两项更正

本报告取代首版第二阶段报告。首版在数值层面基本可复现，但存在两处推理错误，此处如实记录，并给出更正后的口径。

### 2.1 层贡献分解必须是按节点数加权的层总贡献

首版把四个距离层**层内均值的等权平均**当作全节点 margin 的可加分解，即误用了

$$\frac{1}{4}\left(\bar\gamma_{0}+\bar\gamma_{1}+\bar\gamma_{2}+\bar\gamma_{>2}\right).$$

正确的可加分解为

$$\Gamma_b^{all}=\sum_{\ell}\frac{N_{b,\ell}}{N_b}\bar\gamma_{b,\ell}=\frac{1}{N_b}\sum_{\ell}\sum_{n\in\ell}\gamma_{b,n}.$$

即层的**总贡献**是该层逐节点贡献之和，层内均值必须按节点数加权才能还原全节点 margin。实测四个层的节点数差异很大（0-hop 1.00 个、1-hop 1.93 个、2-hop 2.68 个、大于 2-hop 10.40 个），因此等权平均必然偏离。

首版产物中已经暴露该问题：Oracle 的 `gamma_all_mean` 为 $2.0967\times10^{-3}$，而所谓 `layer_weighted_mean` 为 $3.1542\times10^{-3}$，两者不相等。本版改用正确分解后，闭合误差在全样本为 $0.00\times10^{0}$、在测试划分为 $0.00\times10^{0}$，即精确闭合；作为对照，等权层平均的误差分别为 $1.06\times10^{-3}$ 与 $9.95\times10^{-4}$。

### 2.2 固定规模对照必须是全节点与局部的比较，而非随机与局部的比较

首版的固定规模对照比较的是“从全部节点随机抽 $m$ 个”与“从候选条件邻域抽 $m$ 个”。这不是全节点距离与局部距离的比较，而**随机等规模节点子集对候选条件等规模节点子集**的比较，因此不能作为“全节点相对局部”的证据。

本版把对照改为：两者使用**相同的有效节点数 $m$**，比较

- `full`：从全部 $N$ 个观测节点中抽取 $m$ 个节点，对**全部候选**使用同一个子集 $S$；
- `local`：对每个候选 $c$ 从其候选条件邻域 $\mathcal N_c^{(h)}$ 中抽取 $m$ 个节点，得到该候选自己的子集 $S_c$。

此外单独报告 `candidate_matched`：每个候选在其自身邻域的全部节点上取均值，用于与 `local` 对照，隔离“邻域内抽样”带来的方差。

同时必须声明 `local` 口径的固有限制：由于每个被评分候选 $c$ 使用**不同的节点集合** $\mathcal N_c^{(h)}$，不同候选的距离不在同一评分空间内，其数值不可直接比较。该限制适用于本报告全部 `local` 与 `candidate_matched` 结果。

## 3. 逐节点距离口径

$$R_{b,c,n}=\frac{1}{2K_n T}\sum_{t=1}^{T}\sum_{f\in\mathrm{active}(n)}\frac{(X_{b,n,t,f}-\widehat S_{b,c,n,t,f})^2}{s_{n,f}^{2}+\varepsilon}$$

实测活跃通道数：11 个三相母线各 6 个，3 个两相母线（645、646、684）各 4 个，2 个单相母线（611、652）各 2 个。

候选间真实响应差异量以真实候选为参考。等权聚合下满足精确恒等式

$$\Gamma_b^{all}(j)=\frac{1}{N}\sum_{n}\gamma_{b,n}(j),\qquad \gamma_{b,n}(j)=R_{b,j,n}-R_{b,c_b^\ast,n},$$

实测最大绝对闭合误差为 **0.0**。

## 4. 4.1 真实响应判别差异（Oracle 口径）

### 4.1.1 排序上界

以真实候选响应当作预测时：

- 全样本 640：Top-1 = **1.0000**、Top-3 = 1.0000、Top-5 = 1.0000、平均真实 rank = **0.000**
- 测试划分 96：Top-1 = **1.0000**、Top-3 = 1.0000、Top-5 = 1.0000、平均真实 rank = **0.000**

即在不含预测误差的真实响应层面，全节点等权聚合已经给出完全正确的候选排序。

### 4.1.2 按节点数加权的层贡献分解

`physical hardest negative` 的逐节点 margin 贡献，按真实故障位置分层。必须区分**单节点均值**与**层总贡献**两个不同量：

全样本 640：

- 0-hop：节点数 1.00，单节点均值 $+3.6095\times10^{-3}$，总贡献 $+3.6095\times10^{-3}$
- 1-hop：节点数 1.93，单节点均值 $+3.7386\times10^{-3}$，总贡献 $+5.0718\times10^{-3}$
- 2-hop：节点数 2.68，单节点均值 $+3.5739\times10^{-3}$，总贡献 $+6.3762\times10^{-3}$
- 大于 2-hop：节点数 10.40，单节点均值 $+1.6948\times10^{-3}$，总贡献 $+1.8490\times10^{-2}$

测试划分 96：

- 0-hop：节点数 1.00，单节点均值 $+3.3619\times10^{-3}$，总贡献 $+3.3619\times10^{-3}$
- 1-hop：节点数 1.94，单节点均值 $+3.8450\times10^{-3}$，总贡献 $+4.9323\times10^{-3}$
- 2-hop：节点数 2.68，单节点均值 $+3.8018\times10^{-3}$，总贡献 $+7.3555\times10^{-3}$
- 大于 2-hop：节点数 10.39，单节点均值 $+1.7685\times10^{-3}$，总贡献 $+1.9539\times10^{-2}$

由此得到两个方向相反的结论：

- **单节点均值：近端更大。** 1-hop 相对大于 2-hop 为 2.206（全样本）与 2.174（测试划分）。
- **总贡献：远端更大。** 大于 2-hop 相对 1-hop 为 3.646（全样本）与 3.961（测试划分）。

即近端节点的**单节点**候选间判别贡献约为远端的 2.2 倍，但由于远端节点数约为近端的 5.4 倍，远端的**总**贡献反而是近端的 3.6 至 4.0 倍。先前把“每节点贡献较大”表述为“区域贡献较大”是不成立的。

区域汇总（单节点均值口径）：全样本全节点 $+2.0967\times10^{-3}$、1-hop 近端 $+3.7386\times10^{-3}$、大于 2-hop 远端 $+1.6948\times10^{-3}$；测试划分全节点 $+2.1993\times10^{-3}$、近端 $+3.8450\times10^{-3}$、远端 $+1.7685\times10^{-3}$。两个口径下近端与远端的正值比例均为 1.000。

## 6. 5.3 修正后的同规模对照

下表为描述性点估计。每个单元的含义：`unrestricted` 使用全部 16 个节点；`full(m)` 从 16 个节点随机抽 $m$ 个、对全部候选用同一子集；`local(m)` 各候选从自身候选条件邻域抽 $m$ 个；`candidate_matched` 各候选使用自身邻域的全部节点。

Oracle 口径：全部可用单元均为 1.000，与节点集合无关。这是因为真实候选在其自身节点上响应完全匹配，`argmin` 恒为真实候选。

predictor 口径（全样本 640，student）：

- $h=0$，$m=1$：unrestricted 0.122、full 0.113、local 0.062、candidate_matched 0.062
- $h=1$，$m=1$：unrestricted 0.122、full 0.120、local 0.052、candidate_matched 0.056
- $h=2$，$m=1$：unrestricted 0.122、full 0.109、local 0.058、candidate_matched 0.058
- $h=2$，$m=3$：unrestricted 0.122、full 0.120、local 0.056、candidate_matched 0.058
- $h=0$ 或 $h=1$ 且 $m=3$：local 不可用（候选条件邻域节点数少于 3），按设计记为不可用、不补零

predictor 口径（全样本 640，teacher）：

- $h=0$，$m=1$：unrestricted 0.173、full 0.155、local 0.066、candidate_matched 0.066
- $h=1$，$m=1$：unrestricted 0.173、full 0.159、local 0.064、candidate_matched 0.062
- $h=2$，$m=1$：unrestricted 0.173、full 0.152、local 0.067、candidate_matched 0.059
- $h=2$，$m=3$：unrestricted 0.173、full 0.169、local 0.062、candidate_matched 0.059

测试划分 96 的方向一致。student 在 $h=0, m=1$ 为 unrestricted 0.115、full 0.104、local 0.073；teacher 为 unrestricted 0.177、full 0.188、local 0.042。

可读出的三点，均需附带第 2.2 节的评分空间限制：

- **`full(m)` 与 `unrestricted` 接近**：例如 student $h=2, m=3$ 时 full 0.120 对 unrestricted 0.122，说明在全节点内固定规模抽样基本保留了全节点排序信息。
- **`local(m)` 低于 `full(m)`**：差值在全样本为 $-0.045$ 至 $-0.092$（student）、$-0.083$ 至 $-0.107$（teacher）；在测试划分为 $-0.031$ 至 $-0.062$（student）、$-0.083$ 至 $-0.146$（teacher）。
- **`candidate_matched` 与 `local(m)` 接近**：说明上述差异不主要由邻域内抽样方差造成。
- 由于 `local` 中每个候选使用各自节点集合、评分空间不一致，且 Oracle 在同类构造下恒为 1.000，上述差值**不能**直接解读为“局部聚合损害排序”。

## 7. 设计第 7 节判定标准的逐条核对

**条件 1：真实响应判别差异在近端与远端之间有稳定方向。**
满足（单节点均值口径）。Oracle 下 1-hop 单节点均值约为大于 2-hop 的 2.2 倍，两个口径的正值比例均为 1.000。但需同时记录：按总贡献口径方向相反，远端为近端的 3.6 至 4.0 倍。

**条件 2：远端 margin 贡献显著小于近端。**
口径依赖。若指单节点均值，Oracle 下满足（比值 0.453 / 0.460，区间不重叠）；若指总贡献，则不满足且方向相反。predictor 口径下两种口径均不满足：student 单节点近/远为 1.045（全样本）与 1.166（测试划分），已无 Oracle 中 2.2 倍的差异。

**条件 3：在固定有效节点数的对照中，全节点对应的节点贡献仍出现可重复的 margin 缩小、正 margin 比例下降或排序翻转增加。**
按修正后的 `full(m)` 对 `local(m)` 对照，`full(m)` 一致高于 `local(m)`，即限制在故障邻域后排序变差，方向与命题预期一致。但该结果受第 2.2 节的评分空间限制，且在 Oracle 同类构造下恒为 1.000，因此**不能判定为支持**，只能记为方向性观察。

**条件 4：变化在 Oracle 与 predictor 两个层面至少方向一致，或能明确归因于 predictor 误差。**
不满足方向一致。Oracle 下近端单节点优势为 2.2 倍，predictor 下缩减到 1.0 至 1.4 倍且 teacher 在全样本变号。但**不能**据此单独归因于 predictor 误差，因为本实验未在共同节点集合上完成全节点与局部聚合的可比实验。

**条件 5：候选条件局部距离在不读取真实位置的情况下仍显示同方向改善。**
不满足。如第 6 节，`local(m)` 一致低于 `full(m)`，未显示同方向改善。

**综合判定**：条件 1 满足（单节点均值口径，且总贡献口径方向相反），条件 2 口径依赖，条件 3 仅在受限解释下为方向性观察，条件 4、5 不满足。因此本实验**既不能得出“全节点距离没有稀释局部判别差异”，也不能单独归因于 predictor 残差**。

## 8. 独立复核及其边界

`code/method-a1/scripts/verify_relative_response_stage2.py` 不导入主审计模块，独立重算活跃通道掩码、逐节点距离、`physical hardest negative`、等权聚合恒等式、排序指标、按节点数加权的层分解与层总贡献，并与主审计的 `audit_summary.json` 逐项比对。

两个口径的复核结果均为 `cross_check_all_match = true`，各 20 项检查全部通过，恒等式闭合最大绝对误差均为 **0.0**。

**复核的边界必须明确**：该复核验证的是数组计算一致性、逐节点均值能否恢复全节点均值、Top-K 可复现性与两脚本输出一致性。首版报告中，复核脚本照抄了主审计的层均值等权平均定义，因此两侧一致却同时错误，**复核未能发现该错误**。本版已把正确分解与等权平均的闭合误差分别写入产物（`closure_error` 与 `equal_layer_error`），使定义层面的错误可由数值直接暴露。但复核仍**不覆盖**指标定义、对照设计与推理链条的正确性；独立复核通过不等于实验推理成立。

## 9. 结论与不能外推的内容

### 9.1 目前可以支持的结论

1. 在真实响应与共同的全节点距离下，当前 16 个候选在该数据集上完全可排序（Oracle Top-1 = 1.0000、平均 rank = 0.000）。
2. 真实响应的**近端单节点**候选间差异平均更大，约为远端的 2.2 倍。
3. 由于远端节点数约为近端的 5.4 倍，远端的**总**候选间差异贡献反而是近端的 3.6 至 4.0 倍；远端节点不能视为无效节点。
4. 因此“真实物理响应本身不可区分”不是当前 640 事件上的主要瓶颈。
5. 当前 predictor 的全节点 margin 均值为负，且在 Oracle 中清晰的近端/远端单节点差异（2.2 倍）在 predictor 中缩减到 1.0 至 1.4 倍，teacher 在全样本甚至变号；预测误差确实破坏了真实响应中的候选排序结构。

### 9.2 目前不能支持的结论

- 不能声称近端区域的**总**判别贡献大于远端。
- 不能声称全节点聚合一定稀释了局部判别信息。
- 不能声称候选条件局部距离不适合诊断。
- 不能声称 predictor 一定没有学习局部结构。
- 不能把“变化归因于 predictor 残差而不是全节点聚合”，因为本实验**没有在共同节点集合上完成全节点与局部聚合的可比实验**，因而不能排除聚合方式与 predictor 误差之间的交互。

### 9.3 最稳妥的总体表述

> 第二阶段确认了：真实响应空间中近端节点的单节点候选差异通常较大，但远端节点由于数量更多仍贡献更大的总量；在当前 predictor 中，真实局部差异没有稳定转化为正的排序 margin。现有候选条件局部距离实验由于不同候选使用不同节点集合、评分空间不一致，不能用于判断局部聚合是否优于全节点聚合。因此本实验尚不能归因于“全节点距离没有稀释局部差异”，也不能单独归因于 predictor 残差。

### 9.4 不能外推的内容

- 本结果只适用于 `paired-v1` 全观测、全候选、单一 IEEE13 拓扑族、单一随机种子 342 与常规阻抗范围 $[0.1,100]\ \Omega$ 的数据集。
- 全样本 640 口径包含该 checkpoint 的训练事件（448 个），其 predictor 数字含自评价成分，不作为泛化性能结论。
- 本实验未重新训练任何模型，对训练侧干预的效果没有任何结论。
- 本实验未测量判别信息在节点间的理论分布，只测量现有 predictor 在逐节点距离上的实际表现。
- 第 6 节的同规模对照为描述性点估计，未附事件级区间；`local` 与 `candidate_matched` 口径存在第 2.2 节所述的评分空间不一致问题。
- 本实验不构成对 Method-A1 方法有效性或任何距离设计决策的证据。

## 10. 若继续实验需要先修正的两点

1. **区域贡献必须使用节点数加权的总贡献**，不能使用层内均值的等权平均；报告层结论时必须同时给出单节点均值与总贡献，并注明两者方向可能相反。
2. **所有候选必须在同一个节点集合上计算距离。** 真实位置邻域只能作为 Oracle 分析，不能直接把不同候选的局部邻域分别用于候选排序。若要判断“局部聚合是否优于全节点聚合”，应比较 $D^{all}(c)$ 与 $D^{mask}(c)$ 在**相同节点数**下的表现，且使用同一子集 $S$ 对全部候选评分；候选条件邻域口径只能作为独立的探索性对照，并明确标注其评分空间不一致。
