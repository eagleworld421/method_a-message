# Method-A1 E4-A0/R1 未知故障阻抗覆盖归因修订结果摘要

## 一、修订结论

本次先审计代码、数据和既有输出，再重新执行 pilot 与 confirmation。旧报告的 CI/CS 独立方法结论、严格错排置换方向、CD 密度解释、弱 `WRONG_GRID` 对照、CM 温度解释和重复模板等预算解释均不再接受。

R1 的正式总体判定为 `证据不足`。CIS 相对 C0 的 Top-1 和严格错排改善方向在正确的成对统计下成立，但独立插值保真度未达冻结阈值；CD 未超过同规模随机阻抗扩容对照；CM 虽使用 pilot residual 间隔尺度推导温度，仍不得据此宣称已形成可部署方法。由于 CIS 保真度门未通过，本任务不条件性批准 E4-A1，也不实施 E4-A1。

## 三、错误分类与 R1 修订

- 分析实现：严格错排率、真实 rank 和并列集合均为越低越好；R1 对这些指标使用下尾块置换，并报告改善量、改善区间和检验方向。
- 实验定义：CD 等级为 `3, 7, 13, 19`，每级覆盖同一完整开发范围且逐级嵌套；不再用密度 rank 前缀代表完整范围。
- 实验臂：`A0-CI` 与 `A0-CS` 合并为 `A0-CIS`，两者只保留历史别名，不作为独立方法思想。
- 对照定义：`A0-CIS__BROKEN_PAIRING` 在同一候选、同一物理故障规格和同一阻抗集合内置乱阻抗—响应配对，保持网格与预算不变。
- 解释限制：原始模板数、独立故障规格数和每一故障规格的阻抗结点分别报告；重复模板不增加独立假设，不作为候选等预算证据。
- CM：温度候选由 pilot residual 候选间隔尺度推导；若温度效应不可识别，CM 只能作为诊断臂。

## 五、正式确认结果

- `A0-C0` Top-1：`0.4461`；`A0-CD`：`0.5954`；`A0-CIS`：`0.8373`；`A0-CM`：`0.7799`。
- `A0-CD` 相对 C0 的 Top-1 增益 `0.1493`，严格错排下降 `0.1507`，但相对随机阻抗扩容为 `-0.0938`，CR 恢复比例 `0.3530`，判定 `证据不足`。
- `A0-CIS` 相对 C0 的 Top-1 增益 `0.3912`，95% 改善区间 `[0.3553, 0.4314]`；严格错排下降 `0.3995`，改善区间 `[0.3611, 0.4387]`；相对同预算随机搜索增益 `0.0644`，改善区间 `[0.0560, 0.0743]`；相对破坏配对对照增益 `0.1389`，改善区间 `[0.1171, 0.1586]`；CR 恢复比例 `0.9250`。但插值保真度未通过，故 CIS 判定 `证据不足`。
- `A0-CM` 相对 C0 的 Top-1 增益 `0.3338`，严格错排下降 `0.3359`，CR 恢复比例 `0.7893`；由于其未形成独立可部署保真度证据且需按温度可识别性解释，判定 `证据不足`。
- 正确下尾统计：CIS 严格错排置换 `p=0.00249`，方向为 `less`；Top-1 使用上尾 `greater`。旧报告中的严格错排 `p=1` 不再适用。
- CR/CRC Top-1 分别为 `0.8690` 和 `0.9870`，仅作评价上界，不作部署方案或训练输入。

## 六、独立插值保真度

开发模板在校准阻抗上插值，并与真实 OpenDSS 校准响应逐响应比较；同时比较完整候选排序、真实母线 rank 和 hardest-negative。总体结果为：

- 响应 MSE：`6.1994e-05`；相对响应 MSE：`3.7131`；
- 完整候选排序一致性：`0.0`；真实母线 rank 一致性：`0.8978`；hardest-negative 一致性：`0.4104`；
- `R<1`：相对 MSE `0.00948`，真实母线 rank 一致性 `0.8926`；
- `1<=R<10`：相对 MSE `0.00396`，真实母线 rank 一致性 `0.9148`；
- `10<=R<100`：相对 MSE `9.2741`，真实母线 rank 一致性 `0.8833`；
- 保真度判定：`false`。这意味着正式 CIS 收益不能直接解释为连续插值器忠实复现真实阻抗响应。

## 七、候选对称性、预算与泄漏

- 候选对称性类型为 `conditional`：给定物理故障规格时，候选使用相同的 19 点阻抗网格；这不是全局模板数量对称。
- 原始模板数随候选可行故障规格数变化，确认集示例包括 `1254`、`456` 和 `114` 三类；独立故障规格数也不同。不得通过重复填充将其表述为独立假设相等。
- `true_location_visible=false`、`true_impedance_visible=false`；标签移除不变量、候选重编号等变和条件阻抗网格审计均通过。
- 同预算比较只比较同一插值族、同一目标网格预算；不使用重复模板声称等预算。

## 八、分层和边界

正式测试阻抗均位于开发范围内，R1 只验证区间内插，不验证外插。样本级与候选级输出均包含原始候选模板数和独立故障规格数，可按候选计数分层复核。检测指标不替代定位指标，也不能证明显式阻抗预测是必要的。

当前证据仅适用于 IEEE13、理想 OpenDSS、全节点观测、当前拓扑、当前模板库和当前阻抗范围；不外推真实传感器、S2/S4、跨拓扑、预测器或学习型诊断空间。

## 九、E4-A1 条件

只有当 CIS 同时通过正式定位收益、严格错排下降、同预算随机搜索、破坏配对、CR 恢复比例和独立插值保真度门，才允许条件性设计 E4-A1。R1 的保真度门未通过，因此本任务不进入 E4-A1。
