# Method-A1 决策流程总结

## 一、A1 是什么，以及为什么采用 A1

Method-A1（反事实稠密监督方法）是一种故障定位框架，而不是单一的分类器。它对候选故障位置 $k$ 分别预测候选物理响应 `S_hat(k)`，再将预测响应与实际观测比较，通过候选残差完成定位：

$$
`k_hat = argmin_k d(X_obs, S_hat(k))`
$$

采用 A1 的原因来自既有方法的明确边界：

- Method-B 的 Top-5 候选覆盖率已经较高，说明候选召回不是首要瓶颈；但真实位置在候选集合中的第一名比例不足，主要问题是候选排序。
- Method-C 主要约束同一真实故障在不同观测视图下的一致性，对非真实候选没有直接的物理响应监督，最终物理验证可能退化为模型使用自身输出评价自身。
- OpenDSS 能够对同一事件枚举所有候选故障并生成对应响应，因此可以为真实候选和错误候选提供稠密反事实监督。

因此，A1 将原来的“直接预测故障位置”改写为“比较候选物理假设”：如果故障发生在候选 $k$，应产生什么响应；该响应能否解释当前观测；真实候选与最难错误候选之间的物理差异是否足以支撑排序。

## 二、端到端决策链

### 1. 先建立候选响应空间，而不是直接选择新表示

先固定 OpenDSS、IEEE13、正确拓扑、全节点观测和全候选离线响应库，建立 S0 闭环。这样可以把部分观测、拓扑错误、传感器噪声和跨拓扑差异暂时隔离。

同时建立 Oracle 排序，区分两件事：真实响应本身是否可分，以及 predictor 是否能学到这种可分性。Oracle Top-1 达到 1.0，说明当前 S0 下存在故障位置信息；但 hardest-negative physical gap 很小，说明可分差异可能被 predictor 误差淹没。

### 2. 用 Z 路线检验“可学习性”假设

在不改变物理语义的前提下，尝试共享映射 `Z = E_theta(S)`，目标是降低无关误差、提高误差相对于候选间隔的比例，而不是凭空制造故障信息。

Z 路线一虽然代码闭环可运行、Top-1 略有改善，但 rho 改善门未通过，参数扫描和 identity、random、label-shuffle、候选置换对照也未发现可靠配置。因此不能据此确定学习型新表示。

### 3. 建立 E0–E7 证据链

由于不能预先假定诊断几何是瓶颈，决策流程改为：

1. E0：验证故障信息是否存在且高于噪声边界；
2. E0-COV：排除阻抗、工况模板覆盖不足；
3. E1：验证覆盖控制后是否仍存在跨工况排序效应；
4. E2/E3：仅在确有独立因素效应时进行因素识别或干预；
5. E4：区分覆盖、predictor 和诊断距离结构瓶颈；
6. E5：独立验证物理邻近关系能否作为约束；
7. E6/E7：再验证 S1–S4、阈值、不确定性和独立数据泛化。

### 4. E0、E0-COV 与 E1 的条件决策

E0 显示检测和 Top-K 定位信息充分，但唯一母线分离未超过噪声边界。因此不能把问题概括为“信息不足”，也不能立即断言“诊断几何有问题”。

E0-COV 显示阻抗覆盖带来主要定位恢复，阻抗—工况联合覆盖还有额外收益；同规模随机扩容不能完全解释该提升。因此必须先把覆盖因素纳入解释，不能直接把 Top-K 下降归因于表示空间。

E1 在覆盖控制后发现跨工况 rank 变化大幅下降，说明原始排序变化主要由模板覆盖不足造成。因此暂时跳过 E2/E3 的因素识别路线；局部错排关系则留给 E5 独立复核。

### 5. PI 的提出原因：由 E0-COV 推导出的待验证假设

PI 不是因为“训练期知道阻抗、部署期不知道阻抗”这一接口事实本身而被选中。真正的提出依据是：

1. E0-COV 证明阻抗覆盖显著影响候选定位恢复；
2. 这表明故障阻抗是候选响应生成中的重要条件变量；
3. E4-A0/R1 又显示未知阻抗条件化可能提高定位，但连续插值保真度尚未通过；
4. 部署时不能读取仿真中的真实阻抗，因此不能简单把阻抗作为普通输入。

由此提出 PI 假设：训练期让特权教师读取真实阻抗，学习候选位置与阻抗共同决定的响应结构；部署期让学生只读取合法观测和候选物理描述，检验其中可由普通输入支持的部分能否迁移。这里的 PI 是响应回归和条件迁移设计，不是标签噪声 PI，也不等于已验证的方法。

paired-v1 先为每个物理事件保存一个真实阻抗下的全候选配对响应，严格隔离学生字段、教师字段、评价字段和仿真隐变量。连续阻抗轨迹 trajectory-v2 暂缓，因为它需要多阻抗结点、独立 OpenDSS 调用记录和单独的数据契约。

### 6. PI 实验后的再决策

160 事件实验中，教师和蒸馏没有稳定改善无阻抗学生；学生响应误差大于 Oracle physical gap，hardest-negative consistency 较低，触发停止条件，不再增加复杂 PI 结构。

640 和 1600 事件扩大实验显示样本量增加能改善 Top-K 和平均 rank，但响应误差仍大于候选真实间隔，distill 也没有稳定收益。因此只能认为样本量是限制因素之一，不能认为 PI 已经有效。

### 7. 误差—间隔审计与当前方法边界

由于 predictor error 持续大于 physical gap，进一步审计条件 Bayes risk、时序误差界和信息论下界。现有论文主要针对未来时序预测、单变量或平稳过程，不能直接给出 A1 多节点反事实响应的严格下界。

当前更稳妥的对象是固定部署信息和固定加权距离下的候选级条件风险，并逐事件输出：

- 真实候选预测误差 $e_k$；
- 错误候选间隔 `delta(k,j)`；
- 同一距离空间中的根号误差比值 `rho_RMSE`。

只有在完成该审计后，才能判断主要瓶颈究竟是 predictor、不可观测条件还是诊断几何。

## 三、按时间顺序的决策记录

### 2026-09-02：选择 A1 并建立 S0

- 依据 Method-B 的候选覆盖与排序差距，以及 Method-C 缺少错误候选物理监督的问题，采用反事实稠密监督框架 A1。
- 选择 OpenDSS、IEEE13、全候选响应库、TCN+普通拓扑 GNN。
- 首轮固定正确拓扑和全节点观测，隔离其他因素。

### 2026-09-03 至 2026-09-10：Oracle、S1–S4 与 Z 路线

- 建立 signature library 和 S1–S4 Oracle 流程。
- 发现 Oracle 可区分候选，但 hardest-negative gap 较小。
- 实现 Z 路线一验证可学习性改善，但未通过 rho 改善门。

### 2026-09-14 至 2026-09-15：转向证据驱动流程

- 固定“先信息充分性、再因素归因、再瓶颈归因、最后选择方法”的 E0–E7 流程。
- E0 确认检测和 Top-K 信息存在，但唯一母线稳定性不足。

### 2026-09-16：E0-COV 与 E1

- E0-COV 确认阻抗覆盖是重要定位因素，联合覆盖还有额外收益。
- E1 表明覆盖控制后跨工况排序变化基本消失，因此暂不进入 E2/E3。

### 2026-09-17：E4-A0/R1

- 未知阻抗条件化改善定位，但插值保真度和完整排序一致性未通过。
- 由此提出 PI：阻抗作为训练期特权条件，由教师学习，再检验无阻抗学生是否能迁移。

### 2026-09-18：E5 pilot

- 单一 IEEE13 topology/family 无法支持跨拓扑 confirmation。
- 物理邻近关系暂不能成为训练约束。

### 2026-09-19 至 2026-09-20：PI 与扩大样本

- paired-v1、无阻抗学生、特权教师和蒸馏实验完成。
- PI 没有显示稳定迁移收益，停止增加复杂 PI 结构。
- 640/1600 事件表明样本量改善了 Top-K，但未消除响应误差大于 physical gap 的问题。

### 当前决策

- 已确定：候选响应空间是 A1 的基本问题表达。
- 尚未确定：最终 predictor、学习型新表示和 PI 结构。
- 当前优先事项：逐事件误差—间隔审计、predictor-only 误差分析、多种子和多拓扑验证。
- 只有确认诊断几何是独立主要瓶颈后，才重新选择新表示；只有物理关系跨环境稳定后，才将其作为训练约束。
